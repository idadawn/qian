# CLI 约定

- 当前提供静态 dump-config、docs generate、skill-only 文档模板初始化、市场目录解析，以及开发中的批量代码安装/升级、本地列表与移除；文件读取和输出不得执行目标组件或解析 secretRef 或读取私钥。
- 复用 @qian/surfaces，规则改动必须更新 .NET 装配器与共同 TCK。
- 参数错误也输出统一 ErrorDetail，不拼 { error: ... }。

- 市场来源必须先验 Ed25519 签名与 digest，再复用组件校验器；不 checkout 或执行来源内容。未验证市场只允许显式选择的 community 无代码组件。
- `add` 已接入真实包管理器、声明 digest 与实际还原归档复核；组合包完整交付、代码表面切片、引擎、包原生签名/provenance、租户 scope 与中断恢复仍属 S1-RT-011 未完成项。不能用通用包测试替代真实命名 Provider、私有包族发布或平台权限验收。
- 包管理器停止状态不明确时，保留安装锁、日志和备份，不能一边有进程写文件一边回滚。市场校验不得因代码安装而放宽；反向权限、版本和来源均保留在可审阅计划中。
- 组合包通过真实 profile.bundles 组装，每个子组件独立过校验与信任等级检查。预检可从声明引用的实际包补齐 qian 内容，不改宿主依赖、不复制包源凭据；同名内容冲突不能被 force 绕过。父组件不能绕过子组件 required 保护；组合层边界、表面切片和包真实性未全验收前，不能提前关闭完整交付门。
