# 文档生成器约定

- 输入为真实 profile 快照、组件 Schema 与源码；不执行目标组件或构建其项目。
- 对静态事件使用语义绑定，不按字符串或方法短名猜测生产/消费关系。
- 模式不一致必须失败；无法解析的动态事件必须明确标识，不伪造已验证映射。
- 输出保持确定性；敏感 Schema 默认值与样例不可泄漏，secretRef 不解析。
- 规则改动补正反例与真实 CLI 验收；配置与图形以本包 README 为唯一实现说明。

## 模型体验

诊断使用 Definition 的错误码和冻结 ErrorDetail，保留文件与行号。

## 已知限制与延期项

完整编译、TS 运行时事件和文档新鲜度 CI 按 README 的后续任务边界推进。
