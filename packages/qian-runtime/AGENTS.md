# TS 运行时约定

- 公开语义以组件规格 §5 与共用 TCK 为准，不能为上游默认行为降低断言。
- 上游 vendor 文件不得手改；升级时重取来源、许可证与校验清单，重新验证语义差异。
- Context 不泄漏底层实现；scope 两层扁平，目录与执行共用过滤结果。
- Provide / On / Restrict 归属一次 Apply，失败与卸载按逆序等待释放。
- 公共 API 经 API Extractor；禁止在运行时下载插件、加载平台数据库或输出凭据。

## 模型体验

使用冻结错误码与 ErrorDetail，过滤与不存在保持一致。

## 已知限制与延期项

发布名称按 S1-DEC-014 的明确结论实施；库内不承接安装或完整平台功能。
