#10.1 清单与表面校验器

校验器是一个库（Qian.Runtime.Validation / @qian/validation），被 qian doctor / qian pack、装载器（Resolve 阶段）、qian.registry（写入 scope_patches 前）、市场仓库 CI 与 Agent 门面（S4 校验 Agent 生成的草稿组件）共用——组件文件夹（分发形态）与注册表（运行态真相源）用同一校验器（R35）。错误以 { code, pointer, message, allowed? } 列表返回（沿 v1 §4.1），pointer = 文件路径 + JSON Pointer（Markdown 表面指向 front matter 键）。

#10.2 运行时语义 TCK

TCK 是语言无关的场景文件（tck/runtime/*.scenario.yml：给定组件 / 条目 / patch 层 → 期望的挂载顺序、注册可见性、事件结果、释放顺序），由 .NET 与 TS 各自的 harness 执行，两侧必须全部通过（D20.2；ADR-020 §5「语义以本 spec 为准」）。S1 用例：

编号用例期望
T01依赖等待B inject: [X] 先于 A（provides: [X]）进入树；B Pending，A Ready 后 B 才 Apply；顺序 A → B
T02环路A ↔ B 互相 inject；Resolve 失败，诊断列出 A → B → A
T03逆序释放依次注册 e1、e2、e3；Unmount 释放顺序 e3、e2、e1
T04级联卸载与恢复Unmount A（提供 X）后 B 被 Unmount 回到 Pending；重新 Mount A 后 B 重新 Apply，效果栈先清空再填充
T05waterfall 短路三个监听器，中间者不调 next()；第三个未被调用，结果为中间者返回值
T06waterfall 顺序priority 高者在外层；同级按挂载顺序
T07parallel 聚合一个抛异常，其余完成；发起方收到聚合异常且 Partial 含两个结果
T08serial 中断第二个抛异常；第三个不执行
T09bail 首值第一个返回空、第二个返回值；第三个不被调用，结果为第二个的值
T10emit 隔离监听器异常不传播到发起方；其余监听器仍执行
T11模式不一致事件定义 emit，On 传 waterfall；挂载失败
T12scope 遮蔽全局 (Files, upload) 与 tenant:t-001 内同名注册；在 t-001 得 scope 内项，在 tenant:t-002 与全局得全局项
T13restrict 交集对 t-001 施加两个 restriction（保留 {a, b} 与 {b, c}）；List 只返回 b；执行 a 的错误与执行不存在的 z 完全相同
T14无继承agent-session:s-9 看不到 tenant:t-001 的 scope 内注册
T15patch 叠加顺序组合包 {a}、profile patch {b}、CLI overlay {c}；结果 {c}（整体替换无残留），layer 为 CLI 层
T16patch 禁用与再启用、替换 Providerprofile disabled: true + overlay disabled: false ⇒ 条目存在；后层不同 plugin ⇒ 新 Provider 提供同一键，Consumer 不变
T17config 校验先于 Apply不合法 config 的条目 Failed，Apply 未被调用
T18同 scope 重复 Provide第二个条目挂载失败并报出第一个条目 id
T19声明式表面热重载修改 SKILL.md 的 description；ctx.Tools 更新，替换期间读取方只看到旧内容或新内容，代码条目效果栈未变
T20整树 teardown按挂载顺序逆序 Unmount；每个条目满足 T03
T21跨 scope 分发可见性全局监听器收到 tenant:t-001 的分发；tenant:t-002 的监听器收不到
T22optionalInject键缺失时 Apply 执行且 TryInject 为空；键稍后出现不触发重新 Apply
T23独立模式等价同一组 Provider 在 minimal 与 platform 下对同一场景产出相同结果（ADR-019 D19.8 第二条的运行时侧）；S1 由 QA-002 用 TCK 组合包 qian.bundle.tck-platform 与 CRM 样例 Provider 组验证，D19.8 点名的 Files / Authz / Identity.Client 对照见 S1-QA-003 / S1-QA-005（S1-DEC-019 R68）
T24注册表 seam 同名独占与遮蔽两个全局条目向 Identity.Connectors 注册同名 oidc，第二个挂载失败并报出第一个条目 id；tenant:t-001 内注册同名 oidc 后，t-001 的 Connectors.Get("oidc") 得 scope 内项、t-002 得全局项（R38）
T25注册原位替换经 Provide 句柄替换实例后解析得新值，具名注册的 List 顺序与 scope 内注册的可见范围不变；以 inject 依赖该键的条目释放后重新 Apply；条目卸载后句柄拒绝替换，注册无残留
