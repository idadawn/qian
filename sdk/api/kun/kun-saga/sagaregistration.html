Holds AOT-safe, closed-over delegates for a single saga type. Generic types are captured at registration time so no runtime MakeGenericType is needed during execution.

#StartAsync

Starts a new saga instance. Captures TSaga and TContext at registration time, so no reflection is required at call time. Parameters: (contextJson, store, clock, serviceProvider, cancellationToken) → sagaId The context is passed as the typed object (boxed as object). The IServiceProvider is used to resolve the saga's step-0 timeout via SagaRegistration.GetStepTimeout so that SagaInstance.TimeoutAt reflects the actual per-step timeout rather than an arbitrary default.

public Func<object, ISagaInstanceStore, ISystemClock, IServiceProvider, CancellationToken, Task<Guid>> StartAsync { get; }
