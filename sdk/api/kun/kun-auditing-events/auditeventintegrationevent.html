Integration event emitted by AuditingSaveChangesInterceptor for every tracked mutation of an entity registered via services.AddAuditable<TEntity>(). Published through the Outbox with stable id kun.audit.event.v1.

public AuditEventIntegrationEvent(Guid? TenantId, Guid? UserId, string ActorType, string? ActorId, string Action, string? ResourceType, string? ResourceId, string Outcome, string? TraceId, JsonDocument? Metadata, string? IpAddress, string? UserAgent, DateTimeOffset CreatedAt)

#Parameters

TenantId Guid?

Tenant scope; null for non-multi-tenant hosts.

UserId Guid?

User identifier when the acting principal is a human user; null for system / agent actors. When both UserId and ActorId are populated for a user-type actor they should carry the same value.

ActorType string

Kind of actor: "user", "agent", or "system".

ActorId string?

Subject identifier of the actor (claim sub, service id, …).

Action string

Domain-level action identifier, e.g. order.placed or the EF EntityState (Added / Modified / Deleted) when no richer action is in scope.

ResourceType string?

CLR type name of the audited entity (e.g. Order).

ResourceId string?

Primary key of the audited entity as a string.

Outcome string

One of "success", "denied", "error".

TraceId string?

W3C trace id captured from Activity.Current.

Metadata JsonDocument?

Optional caller-supplied metadata. Persisted as raw JSON on the outbox payload. Kept as JsonDocument so the shape is opaque to the framework — consumers decide how to parse it.

IpAddress string?

Remote IP of the originating request, when available.

UserAgent string?

User-Agent header of the originating request, when available.

CreatedAt DateTimeOffset

UTC timestamp at which the audit event was produced.
