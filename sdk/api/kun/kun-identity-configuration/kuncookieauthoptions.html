Options for the cookie session layer wired by AddKunIdentity(id => id.AddCookieSession(...)). The defaults encode the zero-trust baseline Kun.Gateway already applies to outbound cookies.

#Remarks

This options type lives in Kun.Identity (not Kun.Identity.AspNetCore) so non-ASP.NET-Core hosts — worker services that replay a signed-in request, integration tests that synthesize a session — can configure it without pulling the ASP.NET Core dependency. KunCookieAuthOptions.SameSite and KunCookieAuthOptions.Secure use Kun-owned enums (KunSameSiteMode, KunCookieSecurePolicy); the middleware in Kun.Identity.AspNetCore maps them to the equivalent ASP.NET Core values at registration time.
