#SDK

Markdown 链接

本部分只写编程模型与 API：怎样写一个组件、怎样让 Agent 用上它。某个组件怎么装、怎么配，写在组件目录，两边互相链接、不重复。每节按「编程模型 → 示例 → API 参考」组织。

部分包内容
Kun 框架Kun.*底座框架：按锁定版本从 kun 仓库镜像的上手、模块地图、指南、安全、设计说明与变更日志；Qian 的选用与约束见与 Qian 的关系
后端 SDK（.NET）Qian.Runtime、Qian.Plugin.Sdk、各组件的 Qian.* 包上下文 ctx、服务注册、类型化事件、可逆副作用、能力目录、事件分发模式
前端 SDK@qian/runtime、@qian/plugin-sdk、@yue/sdk外壳插件树、MF2 远程模块、插槽
AI SDK—在插件与前端里调模型与 Embedding、写 Agent 原生表面、MCP、Agent 运行时对接

API 参考由工具生成，不手写：.NET 包用 DocFX，TypeScript 包用 TypeDoc。Kun 的 API 参考已生成，Qian.* 与前端包的随 S1-DOCS-002 加入。

「Kun 框架」小节的内容按仓库 Directory.Packages.props 里 KunVersion 锁定的版本从 kun 仓库镜像，API 参考由 DocFX 从同一版本的 Kun.* 包生成，与 Qian 实际依赖的 Kun 始终是同一版本（ADR-021）。
