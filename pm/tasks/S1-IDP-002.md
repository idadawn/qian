## 背景

可嵌入任意 ASP.NET Core 宿主的 OpenIddict 7.x IdP，默认进 `identity` profile（独立 PG schema `identity`、独立 Redis db）：discovery / authorize / token / userinfo / revocation / introspection / end_session / back-channel logout；授权码 + PKCE、refresh 轮换 + 复用检测、`client_credentials`、RFC 8707 `resource`；非对称签名 + JWKS 轮换；每环境一个规范 issuer；access token 15 分钟；内置客户端注册表（平台、官方插件、外壳、CLI）；CSRF 与安全头。

## 验收

- [x] IT：OpenIddict 一致性测试（授权码 + PKCE、refresh 轮换、client_credentials、revocation、back-channel logout）全部通过；refresh 令牌复用被检测并吊销整族
- [x] IT：已修复的 Kun Identity 客户端对真实 `qian-identity` 完成强制 PKCE 的授权码换取，篡改 nonce 的 id_token 被拒绝；记录实际 Kun 包版本、issuer 与客户端配置，不能以协议夹具或外部 IdP 代替（DEC-015，身份服务完成与发布必过）
- [x] 代码审查 + IT：令牌中不含任何权限码；日志中无明文 sid、无密码
- [x] IT：以 `principal_kind = service` 的 `client_credentials` 令牌调用能力成功，`sub = client_id`
- [x] IT：嵌入 `Qian.Identity.Server` 的独立宿主能通过 OpenIddict 一致性测试（ADR-019 D19.8）
