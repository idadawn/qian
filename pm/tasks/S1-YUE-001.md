## 背景

外壳是 `@qian/runtime` 上的一棵 TS 插件树，打包为 `platform` 的 `shell` 组合包（静态制品，经 `gateway` 提供，R31）：`registerRemotes / loadRemote`、`mf-manifest.json` 类型提示与预加载；共享 singleton `react / react-dom / @yue/* / @qian/plugin-sdk`、`engines.yue` 校验；六个插槽 `qian.shell.nav/v1`、`settings/v1`、`user-menu/v1`、`command/v1`、`preview/v1`、`client-action/v1`（输入 Schema + 输出类型，租户 scope 贡献遮蔽全局）；桥接 API `window.__qian.bridge`（`getContext` 只读、`navigate`、`notify`、`invoke` 带幂等键、`registerClientAction`），校验调用方远程 ID 与插槽作用域；npm `@qian/plugin-sdk`。

## 验收

- [x] E2E：`engines.yue` 不满足的远程模块被拒绝加载并在控制台与审计留痕；共享依赖只存在一份 React 实例
- [x] UT：桥接 API 拒绝来自未注册远程或超出声明作用域的调用；`getContext()` 返回对象不可写
- [x] UT：租户 scope 的插槽贡献遮蔽同名全局贡献；客户端动作注册表（名称、参数 JSON Schema、权限、人话描述）可导出 JSON
- [x] 包 `@qian/plugin-sdk` 发布到私有 feed，含注册远程、导航与插槽贡献、`PlatformClient`、拦截器链
