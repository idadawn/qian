## 背景

Button 族、Input 族、Checkbox / Radio / Switch / Toggle / Segmented、Select / Combobox、Field、Dialog / AlertDialog / Sheet / Drawer / Popover / Tooltip / HoverCard / DropdownMenu / ContextMenu、Tabs / Accordion / Card / Separator / ScrollArea / Resizable、Badge / Tag / Avatar / Skeleton / Spinner / Progress / Alert / Toast / Notification / Empty / Result、Breadcrumb / Pagination / BackTop / FullScreen、Icon 统一入口、Descriptions；每个暴露 `data-slot` 与 `data-testid`、机器可读 manifest（props JSON Schema、slots、events、a11y 角色、令牌依赖、示例）。

## 修订范围（2026-10-14）

按产品负责人要求统一使用 Rspress，不再保留 Storybook。51 个组件入口与 manifest 已合并；现已实施文档、演示与测试迁移，保留历史完成日志；正式站点验证完成后恢复 done。

本任务负责 core 的 Rspress 接入、共用示例和测试迁移、Storybook 清理；文档源仍在组件目录，允许修改 website 的收集器/插件/测试接线，不手改生成目录。S1-DOCS-002 复用该接入继续完成通用组件收集及 .NET/TS/HTTP API，不重复建设 core 展示，也不成为本任务的循环前置。

## 验收

- [x] 组件基线：51 个组件入口与配套部件已合并；保留 `data-slot` / `data-testid`、现有公开 API 与统一令牌行为。
- [x] 机器契约：每个组件导出 manifest 并通过控件 manifest JSON Schema 校验。
- [x] Rspress：现有 `/components/yue/` 中每个 core 组件可发现、有独立页面，按 docs-site.md §3.1 提供首屏交互预览、源码展开/复制、安装、用法、组合结构、分场景示例、完整 props 表与键盘/无障碍说明；左右导航可定位组件及章节，令牌页和明暗状态同站可访问，预览/代码/API 均在现有 Rspress 一个入口内。
- [ ] 真实交互：每个可交互组件有可操作示例和「操作 → 可观察结果」断言，至少涵盖输入/校验、选择/值回写、弹层确认/取消与关闭回焦、Tab 切换、Toast/Notification 触发/关闭及适用键盘路径；静态构建后的 Rspress 页面及预览 iframe 在明暗两态跑 Playwright。展示型组件检查真实渲染与状态；全量入口与场景清单相互校验，不能以截图、仅渲染或外站链接替代。正式站点代表性交互实测通过后才能完成。
- [x] Props：从真实 TypeScript 类型生成，覆盖组合部件、继承属性、函数/回调、必填、联合类型和默认值；Button 的 variant/size/loading/disabled、Dialog 的 open/defaultOpen/onOpenChange 必须出现在 HTML 与 Markdown 中。建立 51 入口及部件清单的完整性门禁，禁止用仅可序列化的 manifest 替代完整 API。
- [x] 共用示例与测试：保留默认/悬停/禁用/错误/暗色等适用状态及交互语义；原 126 条 Storybook 用例逐条登记迁移到独立 Vitest 浏览器测试或 Playwright，保留现有单元、SSR、键盘、焦点、ARIA、64 项页面 E2E 的覆盖，无遗漏；Rspress 真正构建页面（含预览 iframe）axe critical / serious = 0，页面异常使 CI 失败。
- [x] 离线与构建：preview 使用本地组件源码；playground 的 Babel/Monaco/worker 与依赖全部同源打包，按需加载且无外部运行时请求，阻断外网后编辑仍能更新预览；HTML、SSG-MD、llms、搜索、站点前缀、深链刷新与明暗首帧通过验证。全站产物继续遵守 100 MB 预算，组件靶场保留已有 Lighthouse 预算。
- [ ] 清理与发布：删除 apps/yue-storybook、CSF/Storybook 专用配置、直接/传递 Storybook 依赖、脚本、缓存配置和 CI 入口；共用 React 示例保留，独立 Vitest/Playwright/axe 保留；更新 README/AGENTS 与命令，验证 frozen-lockfile 安装。CI 全绿合并后，核验正式 Rspress URL 的组件交互与 props 表，才恢复 done。
