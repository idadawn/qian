## 背景

S1-RT-005（PR #123）六条验收成立、done 维持，复核（claude，2026-10-15）发现的实质缺口汇总到本任务整改。要点：E2E 的「前向兼容」没有被验证（参考应用 1.0.0 与 1.0.1 的模型、迁移、代码完全相同，回切后只是同一张表再读一次）；钩子级幂等、失败重试、租约接管在全仓库没有被第二次调用过，且 `lifecycle_runs` 以 `(tenant, plugin, hook, toVersion)` 为主键，升级 → 回切 → 再升级到同一版本时第二次升级钩子会被当作已成功而跳过；`Deprecate / Retire` 零测试，Deprecated 修订可被 Activate / Rollback / Upgrade 到并被无声覆盖为 Active，Retire 后租户仍可挂载与开通已退役版本；Purged / Uninstalled 的租户再次 Provision 不经授权检查；经 Lifecycle 挂载失败时注册表 Outbox 留下 mounted → unmounted 事件对，订阅者会看到一个从未 Ready 的条目被挂载；Reconciler 的装配诊断是本副本内存、不持久；诊断端点没有平台主体旁路；信任根条目解析失败静默跳过；README 对 CA 解析口径与代码不符；租户级 Provision / Upgrade 对 service 组件只读存量健康字段；GitOps 工作目录指向非 git 目录时会被清空；`plugins/qian.lifecycle` 清单仍是骨架。裁决 R88–R90 固定了口径，本任务按其落地。

## 验收

- [ ] E2E：前向兼容实证——参考应用 1.0.1 新增一列并随包迁移（扩展），租户 A 升级后写入含新列的数据，回切 1.0.0 后列表与详情可读、旧代码忽略新列；租户 B 全程不受影响
- [ ] IT：钩子级幂等与重试——tenant-provision 钩子首次抛错后安装行停在 Provisioning、Attempts = 1、`LIFECYCLE_HOOK_FAILED`；重试成功后 Attempts = 2 且示例数据仍只有一条；租约过期后另一调用者可接管；升级 → 回切 → 再升级到同一版本时 tenant-upgrade 钩子再次执行（幂等键加入 fromVersion 或执行序号，R90）
- [ ] UT / IT：Deprecate / Retire 守卫——Deprecated 修订不能被 Activate / Rollback / Upgrade 到（需先显式取消弃用），Retired 修订不能被挂载与开通；`RetireAsync` 在仍有租户停留该版本时返回 `LIFECYCLE_STATE_CONFLICT`（经 S1-AZ-003 的平台超管旁路跨租户查询并审计）
- [ ] IT：Purged / Uninstalled 的租户再次 Provision 须重新 `EntitleAsync`，否则 `LIFECYCLE_NOT_ENTITLED`（R90）
- [ ] IT：失败挂载的事件——经 Lifecycle 挂载或升级失败并恢复前值时发出 `registry.scope.mount-failed.v1`（entryId、plugin、version、reasonCode，同事务入 Outbox），`LifecycleAcceptanceTests` 的破坏性契约用例断言注册表 Outbox 为 mounted → unmounted / mount-failed；README 写明 mounted 表示写入而非 Ready（R90）
- [ ] IT：proto 契约经 Registry scope Reconciler 强制准入的端到端用例（含无对端 fail-closed、有对端兼容 Ready）；Reconciler 的内存诊断二选一并说明：持久化到 `mount_failures`，或在 README 与诊断端点文档写明「本副本最近一次、不持久、多副本各自为政」
- [ ] IT：诊断端点 `GET /api/lifecycle/diagnostics` 接入 S1-AZ-003 的平台超管旁路并审计 `bypass = superadmin`，与注册表 scope 视图同口径；租户主体仍只能读本租户
- [ ] 修复与文档：信任根条目解析失败（时间格式、引用非法）记日志（只记引用与原因）；README 的 CA「每次实时解析」改为与代码一致（首次缓存、轮换需重启）或改为每次解析；租户级 Provision / Upgrade 对 service 组件重新观测健康；GitOps `workingDirectory` 指向不含 `.git` 的已有目录时拒绝而不是清空；`plugins/qian.lifecycle` 清单用 S1-RT-011 的派生机制补齐 inject / provides / runtime 并去掉 `x-skeleton`
