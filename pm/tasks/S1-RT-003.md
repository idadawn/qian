## 背景

ADR-020 D20.2：yue 外壳也是一棵插件树，TS 侧提供与 .NET 相同的 `Inject` / `Apply` / 五种分发 / `ctx.Effect()` / scope 遮蔽与 `restrict` 语义，由同一组 TCK fixture 固化；是否采用现成库由 S1-DEC-001 决定。第 2 波，7.15.1 外壳与 `@qian/plugin-sdk` 的基础。

## 验收

- [x] TCK：运行时语义套件的同一组 fixture 在 TS 侧全部通过（依赖缺失、成环、逆序撤销、五种分发、scope 遮蔽与 restrict）
- [x] UT：scope 化注册——租户 scope 的贡献遮蔽同名全局贡献，供 7.15.1 插槽注册表使用（由 .NET / TS 共用的 TCK 场景 T12 覆盖，`tck/runtime/T12-shadow.scenario.yml`；不另设 TS 专属单测，S1-DEC-019 R74）
- [x] 物理包 `@idadawn/qian-runtime` 发布到 GitHub Packages 私有 feed，消费方通过 npm alias 导入 `@qian/runtime`，带 `.d.ts` 与 README「模型体验」「已知限制与延期项」节；真实私有源安装通过

交付证据：[实现 PR #26](https://github.com/idadawn/qian/pull/26)、[发布核验修复 PR #41](https://github.com/idadawn/qian/pull/41)、[私有源真实消费验收](https://github.com/idadawn/qian/actions/runs/38146120180)。
