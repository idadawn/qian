## 背景

OIDC code + PKCE、`AuthProvider` 契约、刷新队列合并、多租户选择、过期弹窗；后端菜单 → 路由（`menuTypeRegistry`：页面、外链）；租户切换器（令牌重签）+ 平台代管常驻横幅；主题 / 语言切换、用户下拉；403 / 404 / 500 / 离线兜底与 ErrorBoundary；`window.__APP_CONF__`（K8s ConfigMap）；`Preferences` 注入；站内信顶栏弹窗；加载规则：租户 scope 已挂载 ∧ 路由需要的插槽 → `loadRemote`（权益接线在 S1-ENT-002）；令牌不进 localStorage / URL / iframe。

## 验收

- [ ] E2E（R111：与原 S1-YUE-006 验收 1 的真实流程部分合并）：登录（账号密码与 SSO 跳转回调，均经 qian-identity 的 OIDC code + PKCE）→ 多租户选择 → 切换租户 → 令牌重签 → 菜单与权限随之刷新；令牌过期时刷新队列合并并发请求，失败弹过期对话框
- [ ] E2E：参考应用的远程模块在租户 A scope 已挂载时按需加载并出现在导航；在租户 B scope 未挂载时 `mf-manifest.json` 不被请求
- [x] 代码审查：`localStorage` 中不存在 access/refresh token 明文；URL 与 iframe src 中不出现令牌
- [x] E2E：改 ConfigMap 中 `__APP_CONF__.apiBase` 后刷新即生效，不重编译
