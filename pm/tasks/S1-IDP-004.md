## 背景

`sessions:{person}` Redis 索引；失效触发：改密、停用、锁定、租户冻结 / 到期、强制下线、权限变更；并发上限默认 5、单端按端类型；后通道登出双向；`identity_revision` 递增并经网关 `ForwardedClaimTypes` 转发供 7.5 比对；管理面 `GET /api/identity/sessions?person=`、`POST /sessions/{sid}:revoke`、`POST /persons/{id}:revoke-all`、在线用户列表；日志只记 sid 哈希。

## 验收

- [x] IT：改密后该 Person 全部会话 ≤ 5s 内失效；管理员强制下线某会话后其 refresh 被拒
- [x] IT：并发上限 5 时第 6 次登录踢掉最早会话并发出 `session_revoked` 事件；单端模式下 PC 后登录踢 PC 先登录、不影响移动端
- [x] IT：授权变更后 `identity_revision` 递增，旧令牌请求被服务端拒绝
- [x] 代码审查：日志中不出现明文 sid（grep 门禁）
- [x] IT（R95，自 S1-TEN-002 移交）：会话中心订阅 `tenant.expired.v1` / `tenant.suspended.v1` 后，该租户已登录会话在 ≤ 60s 内失效、refresh 被拒
