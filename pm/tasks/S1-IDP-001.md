## 背景

身份与鉴权互为前置须并行、契约先行：Definition 包定义 `ctx.Identity`、`ICurrentUser` / `IAuthenticatedUser`、令牌 claim 规范集（`sub`、`tenant_id`、`membership_id`、`scope`、`identity_revision`、`sid`、`amr` / `acr`，预留 `profile`、`act`）、`IIdentityConnector` / `IAuthenticatorFactor` SPI、`ExternalAssertion`、事件 `identity.login/logout/password_changed/locked/session_revoked.v1`、`Client.type` 枚举含 `agent`。S1-AZ-003 只依赖本包。

## 验收

- [x] UT：`Qian.Identity.Abstractions` 只依赖 `Qian.Runtime` 与 Kun 的事件端口 `Kun.EventBus.Abstractions`（S1-KUN-010 已解除事件实现依赖），通过 PublicAPI 分析器
- [x] UT：claim 规范集与 `contracts/v0` S2S claim Schema 一致；`Client.type` 枚举含 `agent`
- [x] UT：事件 `identity.*.v1` 带稳定 `[IntegrationEventId]` 与 JSON Schema
