## 背景

从 `plugin.json` 与 profile 生成：Deployment（资源、探针、`terminationGracePeriodSeconds ≥ 优雅停机 + 10s`、`automountServiceAccountToken: false`）、Service、NetworkPolicy（默认拒绝，放行网关 → 服务、服务 → PG / Redis / RabbitMQ / Apollo、`permissions.egress` 经出口代理）、ResourceQuota / LimitRange、PDB、ConfigMap（外壳运行时配置 `/app-config.json`、Apollo 引导项）、Secret 模板（只键名）、迁移 Job；Kustomize 只注入 Apollo 引导项。

## 验收

- [ ] UT：参考应用 `plugin.json` 生成的片段含 Deployment / Service / NetworkPolicy / PDB / ConfigMap / Secret 模板 / 迁移 Job，`kustomize build` 通过
- [ ] E2E：生成的 NetworkPolicy 使未声明 egress 的组件访问外网被拒，声明的域名经出口代理放行
- [ ] 检查：Secret 模板只含键名；ConfigMap 只含 Apollo 引导项与外壳运行时配置（同源 `/app-config.json`）
