## 背景

NuGet `Qian.Plugin.Sdk`（`IQianPlugin` 基类、租户 / 身份 / 权限 / 配置 / 事件 / 存储 / 通知 / 调度客户端门面、生命周期钩子基类、默认安全装配、`PluginEnabledMiddleware`）与 `Qian.Plugin.Sdk.Generators`（`[QianPlugin]` / `[Capability]` / `[ExtensionPoint]` / `[Contributes]` / `[Permission]` / `[QianJob]` / `[QianEvent]` → DI 注册 + 派生字段带 `"$generated": true` 合并进唯一 `plugin.json` + JSON Schema）；只依赖 `Qian.Runtime` 与各 `Qian.<X>.Abstractions`。

## 验收

- [ ] 按 [S1-DEC-018](S1-DEC-018.md) 回验 DATA-001：真实 qian.data 的代码字段由源生成器派生、SDK 默认装配可用，Qian 包族在既定私有 NuGet 源锁步发布并能真实还原；未通过前保留组件骨架标记
- [ ] UT：删除代码中的一个 `[Capability]` 但保留 `plugin.json` 中的派生条目，CI 比对失败并指出漂移项
- [ ] UT：源生成器把 `[Capability]` 的 `Description`、`SideEffect`、`PolicyHint`、`RequiredScopes` 写入 `plugin.json` 的 `tools` 表面
- [ ] CI：`Qian.Plugin.Sdk` 的传递依赖中不出现任何 Provider 包与 `Qian.Registry` / `Qian.Lifecycle` / `Qian.Capabilities`
- [ ] UT：`PluginEnabledMiddleware` 读 `ctx.Registry` scope 视图，对未挂载组件的请求返回 404，与不存在无法区分（R32）
