## 背景

NuGet `Qian.Plugin.Sdk`（`IQianPlugin` 基类、租户 / 身份 / 权限 / 配置 / 事件 / 存储 / 通知 / 调度客户端门面、生命周期钩子基类、默认安全装配、`PluginEnabledMiddleware`）与 `Qian.Plugin.Sdk.Generators`（`[QianPlugin]` / `[Capability]` / `[ExtensionPoint]` / `[Contributes]` / `[Permission]` / `[QianJob]` / `[QianEvent]` → DI 注册 + 派生字段带 `"$generated": true` 合并进唯一 `plugin.json` + JSON Schema）；只依赖 `Qian.Runtime` 与各 `Qian.<X>.Abstractions`。
