## 背景

产品负责人 2026-10-17 判定 yue 现有组件（`@idadawn/yue-core` / `yue-data` / `yue-form`）样式不可用，指示前端组件主要参考 shadcn 与参考平台；裁决见 R114 / R115。复核（claude，读令牌、组件配方与文档站实际渲染）定位到三处基础设施问题，先修它们再逐个组件对齐：

1. **边框令牌被对比度测试逼黑**。`packages/yue/tokens/src/registry.json` 的 `--yue-border` / `--yue-input` / `--yue-sidebar-border` 亮色用 neutral-600（明度 0.52）、暗色用 neutral-300（0.82），因为 `tokens.test.ts` 与 `scripts/check-tokens.mjs` 对所有 `kind: color` 的语义令牌一律要求 4.5:1；WCAG 的 4.5:1 只针对文字，控件边界是 3:1（1.4.11），分隔线与装饰性边框不受限。shadcn 的边框明度是 0.922。结果是表格、输入框、卡片、复选框全是粗黑边。
2. **没有字体栈**。全仓 yue 没有任何 `font-family` / `--font-sans` 定义，靶场 `body` 只设背景与前景色，组件在非 Rspress 宿主里落到浏览器默认衬线字体。
3. **类名绕开了 Tailwind 主题映射**。组件写 `bg-[var(--primary)]`、`border-[var(--border)]`，没有 `@theme inline` 把语义令牌注册成 Tailwind 颜色，用不了 `bg-primary/90`、`ring-ring/50` 这类带透明度的 shadcn 配方；hover 靠 `brightness-95`，焦点环是生硬的 `ring-2`，没有 `shadow-xs`、过渡与弹层进出场动画；Dialog 等 Trigger 套着裸 `button` 基类渲染成一行文字；`--yue-button-height`（40px）与 Button 的 `h-9` 脱节。

目标：视觉语言 100% 对齐 shadcn 的 Base UI 风格生成物（`components.json` 的 `style: base-nova`、`baseColor: neutral`、`cssVariables: true`），交互与信息密度对齐参考平台的后台习惯（表格工具栏、查询表单、弹层表单、分页、按钮顺序）。技术栈不变：React 19 + Tailwind v4 + Base UI 1.8 + 源码自有化（ADR-013 D13.1 / D13.7）。

参考材料与用词纪律：用 shadcn CLI 在 scratchpad 里按 `style: base-nova`、`baseColor: neutral` 生成全部对应组件（以及 table / pagination / form / sidebar）当作唯一样式基准逐个比对，需要时直接读 `https://ui.shadcn.com/r/styles/base-nova/<component>.json`；参考平台只看本机调研笔记；本地页面仅观察列表页、新建弹窗、查询表单的形态与密度，借的是后台页面的信息架构、密度与表格 / 表单 / 弹层的交互习惯，不借视觉、不抄代码；任务文件、进度日志、提交信息、PR 说明、代码注释、文档一律写「参考平台」，不得出现其品牌名、仓库名或本机路径，调研笔记不进仓库。

边界：不引入 Radix / antd / MUI 或新的样式方案（CSS Modules、styled 系列），不 patch `@base-ui/react`；不为「好看」放宽无障碍门禁，文字对比度仍 4.5:1、焦点环必须可见；组件内不写死面向用户的文案；不改分层边界 `boundaries.config.mjs`；不改公开 API、`data-slot`、默认 `data-testid`、受控协议与 i18n 约定，`className` 仍只接受字符串。交付分两个 PR：① 令牌 + `theme.css` + 字体 + 对比度门禁分类；② 组件配方、数据表单层、预览与视觉基线。每个 PR `pnpm yue:gates` 与 CI 八项门禁全绿后合并，改了包的公开行为加 changeset（0.x：破坏性 minor，其余 patch）。

## 验收

- [x] UT（tokens）：`registry.json` 每个语义色令牌带 `contrast: text | boundary | decorative`，`tokenContrasts()` / `check-tokens.mjs` / `tokens.test.ts` 按类取阈值（4.5:1 / 3:1 / 豁免）且三类各有一条用例；`--yue-border` / `--yue-input` / `--yue-ring` 等明度对齐 shadcn neutral（亮色 border 0.922、input 等控件边界取满足 R114 3:1 的最浅档（对白底 oklch L 约 0.66：现有色阶 400（0.72）只有 2.5:1 不够、500（0.62）3.6:1 可用，推荐在 scale 加 450 ≈ 0.66；shadcn 的 0.922 只有 1.26:1，这是对 shadcn 的有意偏离，产品负责人 2026-10-17 选定）、ring 0.708、secondary / muted / accent 0.97、muted-foreground 0.556；暗色 border 白 10% alpha、input 同样使用达到 3:1 的灰（白 15% alpha 按浏览器 sRGB 合成后对 0.145 背景约 1.47:1，不能照搬）、ring 0.556、card / popover 0.205、secondary / muted / accent 0.269、muted-foreground 0.708），映射到最近色阶或在 `scale` 加档，不手写散落颜色值；`--yue-radius` 0.625rem 并派生 sm / md / lg / xl；primary 亮色 brand-600、暗色 brand-400，与前景对比 ≥ 4.5:1 的用例通过
