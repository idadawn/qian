## 背景

ADR-020 D20.7：条目 `{ id, plugin, config, scope? }`，层叠 profile → 组合包 → profile `qian.patch.yml` → home 级 patch → `--patch` overlay；条目 `config` 按组件 `config.schema` 校验；随发行版交付 `platform` / `gateway` / `identity` / `standalone` / `minimal` 五个 profile 文件与 base / shell / model-gateway 组合包骨架；`qian --profile <p> --dump-config` 标注每条目来源层。

## 验收

- [ ] E2E：`qian --profile platform --dump-config` 打印整棵插件树并标注来源层；任取一条条目用 `--patch` 替换其 `config` 后生效，再次 `dump-config` 显示来源为 overlay
- [ ] TCK：patch 按 `id` 定位并替换整个 `config` 或插入新条目；条目 `config` 不符合组件 `config.schema` 时启动失败并带 JSON Pointer
- [ ] UT：五个 profile 文件可被装载器解析；`standalone` / `minimal` 不含 `qian.registry` / `qian.lifecycle` / `qian.capabilities`
- [ ] UT：`minimal` profile 仅装 `Qian.Runtime` 与表面装载器，可作 TCK 基准宿主启动
