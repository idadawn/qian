## 背景

R106（2026-10-16）自 S1-DEP-003 拆出：DEP-003 交付镜像构建与供应链流水线，本任务把三个业务镜像接入该流水线并复验。原 DEP-003 的三项验收原文移到这里。

三个镜像承载的业务宿主尚未交付：

- qian-identity 需要 S1-IDP-002 的唯一 issuer 宿主。
- qian-gateway 需要 S1-GW-001 的认证、换签与路由宿主（GW-001 依赖 S1-IDP-005）。
- qian-platform 需要 S1-IDP-005 的 RP 接入，以及 S1-DEP-009 的用户主体平台表面宿主。

S1-YUE-012 的裁决 ⑤（产品负责人 2026-10-24 选推荐项 A）把认证页族与外壳的静态托管提炼成产品扩展，各有集成测试断言响应头，本任务只做镜像接线与实测：

- 认证页族：Qian.Identity.Server 的 `UseQianIdentityPages(dist)` 在 `/login` 下同源托管 `packages/qian-identity-ui` 的构建产物（HTML `no-store`，`/login/assets/` 长缓存，`frame-ancestors 'none'`、`Referrer-Policy: no-referrer`、`nosniff`），`Accounts.SelectionPath` 必须在 `/login` 下。
- 外壳：网关代理路由一律要求认证，静态外壳只能由网关进程自己从目录提供。Qian.Gateway 的 `UseQianShell` / `MapQianShell` 托管外壳构建产物、`/remotes/{组件 id}/` 下已部署组件的远程制品与 `/app-config.json`（ConfigMap 挂成的文件，每次现读、`no-store`）；`MapQianShellBootstrap` 是 bootstrap 聚合端点。外壳与远程制品由 shell 组合包提供给网关 Pod。

输入缺口与恢复核对见 deploy/images/README.md。

只有真实镜像及其全部证据齐全才可勾选。证据包括：digest、构建 SHA、SBOM、扫描报告、验签结果、非 root / 只读运行证据、配置比对结果。DEP-003 的自检镜像、基线探针、minimal 或 Storybook 页面都不能替代。S1-DEP-005 的发布门（S1-DEC-016）显式依赖本任务。

## 验收

- [ ] S1-DEC-029 接续：核验真实 gateway 的 Config / Audit / Data 等完整依赖组合，完成 Linux NativeAOT 发布和运行验证后恢复默认 `build.aot: true` 及相应组件兼容声明；JIT 开发模板不得替代该验收

- [ ] 检查：三个 profile 镜像按 digest 引用、带 Cosign 签名与 SBOM；`gateway` 镜像为 AOT distroless
- [ ] 检查：每个 profile 镜像内 `qian --dump-config` 的输出与 git 中对应 profile + 组合包 + patch 的合成结果一致（配置漂移门禁）
- [ ] 检查：镜像以非 root 运行、根文件系统只读
- [ ] 检查：qian-identity 镜像带认证页族制品并在宿主调用 `UseQianIdentityPages`；镜像上实测 `/login`、`/login/select-tenant` 与 `/login/assets/*` 的缓存与安全头
- [ ] 检查：网关 Pod 拿到 shell 组合包的外壳与远程制品，生产网关宿主调用 `UseQianShell` / `MapQianShellBootstrap` / `MapQianShell`（AOT 发布仍零诊断），运行时配置由 ConfigMap 挂成 `/app-config.json`；镜像上实测 `/`、深链接、`/assets/*`、`/app-config.json`、`/remotes/<组件 id>/mf-manifest.json` 的缓存与安全头，外壳 `index.html` 的 meta CSP 与构建期断言一致；外壳客户端申请已挂载应用能力声明的 OAuth scope
