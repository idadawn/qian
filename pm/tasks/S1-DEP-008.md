## 背景

R106（2026-10-16）自 S1-DEP-003 拆出：DEP-003 交付镜像构建与供应链流水线，本任务把三个业务镜像接入该流水线并复验。原 DEP-003 的三项验收原文移到这里。

三个镜像承载的业务宿主尚未交付：

- qian-identity 需要 S1-IDP-002 的唯一 issuer 宿主。
- qian-gateway 需要 S1-GW-001 的认证、换签与路由宿主（GW-001 依赖 S1-IDP-005）。
- qian-platform 需要 S1-IDP-005 的 RP 接入，以及 S1-YUE-001 的外壳静态制品。

输入缺口与恢复核对见 deploy/images/README.md。

只有真实镜像及其全部证据齐全才可勾选。证据包括：digest、构建 SHA、SBOM、扫描报告、验签结果、非 root / 只读运行证据、配置比对结果。DEP-003 的自检镜像、基线探针、minimal 或 Storybook 页面都不能替代。S1-DEP-005 的发布门（S1-DEC-016）显式依赖本任务。

## 验收

- [ ] S1-DEC-029 接续：核验真实 gateway 的 Config / Audit / Data 等完整依赖组合，完成 Linux NativeAOT 发布和运行验证后恢复默认 `build.aot: true` 及相应组件兼容声明；JIT 开发模板不得替代该验收

- [ ] 检查：镜像以非 root 运行、根文件系统只读；`shell` 静态制品随 `platform` 镜像发布并经 `gateway` 提供
