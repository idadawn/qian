## 背景

`roles`（tenant_id 可空 = 平台角色、builtin、source_pack）、`role_assignments`（主体可为用户 / 组织 / 岗位 / 用户组、有效期）、`grants`；内置角色：平台超管、租户 Owner / Admin / 开发者 / 使用者 + 自定义；有效角色 = 直接授予 ∪ 经组织 / 岗位 / 组获得；`Check` 缺省拒绝；缓存键 `(tenant, membership, identity_revision)` Redis TTL 10 分钟；超管旁路显式声明并审计；`Explain` 返回 `{ decision, matchedRoles[], matchedGrants[], missing[], reason }`。S1 最大单项之一。

## 验收

- [x] IT：`Explain` 对被拒请求返回缺少的权限点与命中角色；对放行请求返回命中链路
- [x] IT：平台超管访问租户资源被放行且审计记录 `bypass = superadmin`；超管不出现在租户成员列表
- [x] IT：把角色授予直接主体后 ≤ 3 秒内获得权限、撤销后 ≤ 3 秒失效（R82：组织 X 的继承依赖 S1-IDP-009 组织目录，移交 S1-AZ-005）
- [x] UT：未注册权限点或无匹配授权时 `Check` 返回拒绝（fail-closed）；`BatchCheck` 与逐条 `Check` 结果一致
