## 背景

S1-YUE-019 偏离 5、19 与补列的「N 条待审核」（R149）：
- 侧栏分组与角标：原型按分组列菜单、带分组标题，「开通申请」带待审核角标。`AppShell` 已支持 `group` / `badge`，但能力导航没有分组与计数的来源。
- 选择页计数：原型选择工作空间的平台卡片写「N 条待审核」，与侧栏角标是同一个数，现在没有数据源。
- 账号区角色：原型显示角色（「租户管理员」「平台超级管理员」）。会话不带角色，现在显示企业名或「平台运营」；选择页平台卡片回到 yue 缺省的「平台运营 · 租户与平台设置」（R147 缺陷 6）。

分组与计数怎么声明（UI 清单字段、计数接口），以及选择页拿计数时怎么鉴权，开工时给出方案。

## 验收

- [ ] UI 清单的菜单项可以声明分组；外壳侧栏按分组显示标题，没有声明分组的菜单照旧显示
- [ ] 菜单计数：页面可声明一个只读的计数来源，按当前主体的权限取数，外壳显示实心角标；平台控制台「开通申请」显示待审核数，审核或驳回后更新；取数失败或超时不影响导航
- [ ] 选择工作空间的平台卡片显示「N 条待审核」，与侧栏角标同一数据源；没有审核权限时不显示
- [ ] `/api/shell/bootstrap` 带当前主体在本工作空间的角色显示名，账号区显示角色；没有角色数据时维持现有回落文案
- [ ] 有 browser 用例（axe critical / serious = 0）、SSR 用例、文档站场景与视觉基线；`pnpm yue:gates`、`pnpm yue:mf` 通过
