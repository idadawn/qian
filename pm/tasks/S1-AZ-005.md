## 背景

`POST /api/authz/check`、`/batch-check`、`GET /api/authz/me/permissions`、`/me/allowed-actions?resource=`、`POST /api/authz/explain`、角色与授权 CRUD；主体解析接 7.4.3 目录（组织 / 岗位 / 用户组归属）；最小角色授权页（菜单 / 按钮级，P1）用 yue 授权树；授权变更操作标 `write` + `confirm`，授予平台超管标 `humanOnly`。

## 验收

- [ ] IT：把角色授予组织 X 后 X 下成员 ≤ 3 秒内获得权限；主归属变化后有效角色随之变化
- [ ] E2E：租户管理页用 RoleSelect / 授权树完成角色授予并在 `Explain` 中可见命中链路
- [ ] UT：授予平台超管的能力标 `humanOnly`；授权变更标 `write` + `confirm`
- [ ] IT（R82，自 S1-AZ-003 移交）：把角色授予组织 X，X 下成员在 ≤ 3 秒内获得权限，移出组织后 ≤ 3 秒失效
