## 背景

装载器读组件文件夹 → 解析表面 → 以 `ctx.Effect()` 注册进 `ctx.Skills / Agents / Commands / Hooks / McpServers / Tools`，scope 取自挂载条目并受 `plugin.json.scopes[]` 约束；hook = 触发源 × 动作 × 分发模式，服务端触发以 `channel = hook` 进审计；`.mcp.json` 只校验、登记、按 scope 过滤并由 `qian add` 装进开发者 Agent 宿主配置；开发态文件监视 / 生产态注册表变更事件触发只 teardown 受影响表面的 effects 后重新注册，`src/` 变更提示滚动重启。

## 验收

- [ ] TCK：一个只含 `skills/` 与 `.qian-plugin/plugin.json`、没有 `src/` 的组件可装入 `minimal` profile 并出现在 `dump-config` 与 `ctx.Skills`；挂载到租户 A scope 后 B 不可见
- [ ] E2E：修改已挂载组件的 `skills/<x>/SKILL.md` 或 `hooks/hooks.json` 后 ≤ 5s 新内容生效、无进程重启；修改其 `src/` 不触发热重载并在 `qian doctor` 中提示需滚动重启
- [ ] IT：`hooks.json` 把 `tenant.created.v1` 桥接到一个能力 URI，租户创建时被触发且审计记录 `channel = hook`；桥接到不存在的能力在装载期被拒
- [ ] UT：服务端 hook 不执行任意 shell；内联 shell 只在 `commands/` 的人类 CLI 侧允许
