## 背景

原 `qian.kernel` 注册表改为平台插件 `Qian.Registry`（`ctx.Registry`）：`IPluginManifestLoader` / `PluginManifestValidator`（JSON Schema 2020-12 + 语义校验，错误带 JSON Pointer）；PG schema `registry` 的 `plugin_artifacts` / `plugin_revisions` / `tenant_plugin_installs` / `scope_patches` / `extension_points` / `contracts` / `capabilities` / `event_types` / `entity_types` / `lifecycle_runs`；租户 scope patch 持久化与合入；`GET /api/registry/scopes/{scopeKey}/entries`；未挂载条目 404 / 403 `plugin_not_mounted` 规则（R32）。

## 验收

- [ ] TCK：缺任一 S1 必填字段、OCI 引用用 tag 而非 digest、`inputSchema` 含 `tenantId`、`inject[]` 引用无人提供的服务键、`scopes[]` 含非法种类的 `plugin.json`，安装失败并返回带 JSON Pointer 的结构化错误
- [ ] UT：`policy.required: true` 只允许出现在 `policy.tier: system` 的平台插件上，否则校验失败
- [ ] IT：对租户 A 写一条 scope patch、B 不写，`GET /api/registry/scopes/tenant:B/entries/<id>` 对持 `qian.registry:scope:read` 者返回 403 `plugin_not_mounted`、`reason = not_mounted`，无该权限者 404
- [ ] IT：scope patch 变更事件触发装载器重新合入，撤销 patch 后 ≤ 5s 生效，不重启进程
- [ ] IT：v1 别名 `/api/kernel/*` 返回同一结果并带 `Deprecation` 响应头（R33）
