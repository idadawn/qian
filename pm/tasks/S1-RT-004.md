## 背景

原 `qian.kernel` 注册表改为平台插件 `Qian.Registry`（`ctx.Registry`）：`IPluginManifestLoader` / `PluginManifestValidator`（JSON Schema 2020-12 + 语义校验，错误带 JSON Pointer）；PG schema `registry` 的 `plugin_artifacts` / `plugin_revisions` / `tenant_plugin_installs` / `scope_patches` / `extension_points` / `contracts` / `capabilities` / `event_types` / `entity_types` / `lifecycle_runs`；租户 scope patch 持久化与合入；`GET /api/registry/scopes/{scopeKey}/entries`；未挂载条目 404 / 403 `plugin_not_mounted` 规则（R32）。

## 验收

- [x] TCK：缺任一 S1 必填字段、OCI 引用用 tag 而非 digest、`inputSchema` 含 `tenantId`、`inject[]` 引用无人提供的服务键、`scopes[]` 含非法种类的 `plugin.json`，安装失败并返回带 JSON Pointer 的结构化错误
- [x] UT：`policy.required: true` 只允许出现在 `policy.tier: system` 的平台插件上，否则校验失败
- [x] IT：对租户 A 写一条 scope patch、B 不写，`GET /api/registry/scopes/tenant:B/entries/<id>` 对持 `qian.registry:scope:read` 者返回 403 `plugin_not_mounted`、`reason = not_mounted`，无该权限者 404
- [x] IT：scope patch 变更事件触发装载器重新合入，撤销 patch 后 ≤ 5s 生效，不重启进程（cody 10-12 日志称通知与补偿读取已实现、逐步断言 ≤ 5 秒，核对后勾选）
- [x] IT：v1 别名 `/api/kernel/*` 返回同一结果并带 `Deprecation` 与指向后继路径的 `Link: <…>; rel="successor-version"` 响应头（R33，组件规格 §9.5）（S1-RT-019 已在 `CapabilityInvokeTests` 断言两个头的全值，核对后勾选）
