## 背景

组件 `qian.realtime`（`Qian.Realtime.Abstractions` / `ctx.Realtime` + `Qian.Realtime`，P1，经 `gateway` 透传）：`POST /api/realtime/tickets`（30s 一次性票据）握手鉴权、URL 不接受 `access_token`；Redis Pub/Sub 背板扇出（用户 / 租户 / 全部）；连接表只在 Redis `rt:conn:{tenant}:{membership}`；事件类型目录与 JSON Schema（`messagePush`、`unReadMsg`、`online`、`logout`、`identityRevisionChanged`）作为 `@yue/sdk` 的类型来源；`IRealtimePush.PushAsync`；`session_revoked` → `logout`；无通道时站内信 / 权限刷新降级轮询。

## 验收

- [ ] IT：用户在两个浏览器连接到不同副本，向该用户 `Push` 一次，两个连接各收到一次
- [ ] IT：票据过期或复用握手失败 401；URL 中不接受 `access_token` 参数
- [ ] E2E：管理员强制下线后该用户前端 ≤ 3s 收到 `logout` 并跳转登录页
- [ ] UT：SSE 事件 JSON Schema 为唯一真相源并生成 TS 类型；实例重启后 Redis 连接表自动清理
