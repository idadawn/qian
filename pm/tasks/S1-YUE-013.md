## 背景

S1-YUE-002 验收复核（2026-10-23，done）里复核方在突变工作区实测出一批「代码正确、口径没有用例钉住」的点（逐条单独施加、只跑相关用例，存活的才列入）；另有独立审读推演出的边界。都不阻断验收，归本任务补齐：

- 强制刷新的并发单飞：`packages/Qian.Identity.Client/IdentitySessions.cs:73` 的 `RefreshNowAsync` 去掉 `_refreshing.AddOrUpdate` 单飞、每次调用各起一次换新，`RelyingPartyTests.会话快照不含令牌…` 仍过——用例只钉「一次强制刷新 = 一次上游换新」，两路并发 `POST /auth/session/refresh` 合并成一次上游换新没有用例。
- 刷新成功但投影失败的分支：`packages/Qian.Identity.Client/IdentityClientEndpoints.cs:79-85` 里 `RefreshNowAsync` 返回新令牌、而 `ValidateAsync(sessionOnly: true)` 投影不出规范身份时只删 Cookie、401，服务端会话条目（已换新的令牌）保留到 TTL；失败分支会删条目（突变 N02 证明），这一分支没有用例，也没写明是否应同样删条目。
- SDK 会话分支的租户上下文校验：`packages/yue/sdk/src/client.ts:182` 会话刷新后 `tenant !== getTenantId()` 即抛 `sdk.error.contextChanged`，去掉后 client.test.ts 17 例全过（tokenProvider 分支有同类用例，sessionProvider 分支没有）。
- 认证页族 provider 的防伪令牌逐次取新：`packages/yue/shell/src/identity-provider.ts` 的 `csrf()` 改成只取一次并缓存，wiring.ssr.test.tsx「每次写请求取新防伪令牌」3 例全过——用例按 `csrf-N` 计数核对，缓存后计数不增；登录后身份变化、旧令牌是否仍被服务端接受只有真实栈 E2E 能证明。
- 路由前缀段边界：`packages/yue/shell/src/router.ts` 的 `matchMenuItem` 去掉段边界（`/customersX` 也命中 `/customers`）1 例全过。
- 独立审读推演的盲区（未实跑，改法都预期不会让现有用例失败）：`client.ts:188` 对 sessionProvider 跳过 `expire()`（刷新说会话仍在、重放仍 401 时应通知一次过期，并断言请求 2N 次）；`client.ts:181` 去掉 `abortable`（被取消的请求应立即失败）以及刷新完成后才到的「晚到 401」（会多触发一次刷新、多轮换一次 refresh token）；`bff-session.ts:68` 去掉「POST 401 → null」（csrf 200 + 刷新 401 应返回 false 而不是抛错，5xx 不应弹过期）；`apps/qian-shell-auth/src/App.tsx:46` 忽略 `conf.authBase`、`main.tsx:8` 非法配置回退缺省值（应只显示 `shell-config-error` 且 0 个请求）、`App.tsx:95` 代管横幅；`packages/qian-identity-ui/src/entry.ts:15` 直接用原值（外源 / 协议相对的 `/connect/authorize?client_id=…`，以及带 client_id 再带 access_token 的用例）；identity-ui `App.tsx:108` 去掉 `safeNavigationUrl` 与连接器完成后 return_url 不限 `/connect/authorize`（ConnectorPage 组件测试）；`identity-provider.ts:168` 直接返回 `redirect_uri`（`javascript:` 与 http: 地址应拒绝）；E2E 第 7 步的 `>=3` / 首次匹配即过改为静置后断言恰好 3 个 401、恰好一次探测、之后无 `/api/` 请求；第 6 步加刷新计数或令牌指纹的 dev 观察量（否则 `DevGateway.cs` 不改 `ExpiresAt` 也照过）；在身份源页面也检查存储（票据只在内存）；两个 index.html 的 `no-referrer` 补构建产物静态断言；`settled()` 会把 Esc 回归的失败推迟到超时，给 `expect` 加 actionTimeout。
