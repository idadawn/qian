## 背景

组件 `qian.gateway`（`Qian.Gateway.Abstractions` + `Qian.Gateway`，`gateway` profile 独立 Pod、可 AOT）在 Kun.Gateway 之上写死安全默认值：回退策略 = 已认证、匿名白名单显式枚举；只信任 `qian-identity` 一个 issuer；外部 Bearer 或 Cookie `qian.sid` 统一解析主体后由 `S2sTokenIssuer` 签 60s S2S（RS256、`kid` 轮换），`aud` = 目标 cluster，禁透传；`ForwardedClaimTypes` 白名单；`KnownNetworks` 只含 Traefik 网段；机器身份同样换签（`principal_kind = service`）。

## 验收

- [x] S1-DEC-029 接续：核验真实 gateway 的 Config / Audit / Data 等完整依赖组合，完成 Linux NativeAOT 发布和运行验证后恢复默认 `build.aot: true` 及相应组件兼容声明；JIT 开发模板不得替代该验收

- [x] E2E：未带凭据访问 `/api/tenancy/tenants` 返回 401；带外壳 Cookie 访问同一路由，下游收到 60s S2S 且 `aud = qian-platform`、`tenant_id` 正确
- [x] IT：S2S 令牌通过 iClaw `s2s-jwt-claims` Schema 校验；`exp − iat ≤ 300s`
- [x] IT：轮换私钥期间（双钥重叠 10 分钟）在途请求零失败；重叠期后旧 `kid` 被拒绝
- [x] E2E：伪造 `X-Forwarded-For` 的请求（非可信网段发出）不改变限流分区与客户端 IP
