## 背景

7.1 「canonical API 集」与 7.18 第 1 项写进分析器：禁 `IgnoreQueryFilters`、禁废弃 API（旧线 `Kun.Storage`、`Kun.Infrastructure` 死接口、废弃签发器与审计拦截器）、集成事件只在命令 handler 发出、写命令必须有 Schema 与 `idempotencyKey`、`Apply` 内注册必须经 `ctx.Effect()`、组件库引用 `Qian.Registry` / `Qian.Lifecycle` / `Qian.Capabilities` 或任何 Provider 包即报错。

## 验收

- [ ] TCK：故意写一个跨租户读取的查询（`IgnoreQueryFilters`），分析器编译期报错；绕过分析器后 TCK 越权探测用例失败
- [ ] TCK：在 `Apply` 内不经 `ctx.Effect()` 直接注册服务，分析器报错
- [ ] UT：引用旧线 `Kun.Storage.IFileStorage`、`Kun.Infrastructure.IRepository` 或废弃签发器即编译错误
- [ ] UT：缺少 Schema 或 `idempotencyKey` 的写命令、在非命令 handler 处发布集成事件，分析器报错
