## 背景

把 `ctx.Entitlement` 接进网关 `PluginEnabledTransform`、SDK `PluginEnabledMiddleware`、外壳远程模块加载三处：未授权、未挂载、被 restrict 一律 404 / 不加载，与不存在无法区分（R32）；与 7.8 特性开关正交。

## 验收

- [ ] E2E：对租户 B 撤销参考应用授权后 ≤ 5s：网关 404、SDK 404、外壳菜单消失（与不存在无法区分，R32）；重新授予后恢复
- [ ] IT：已授权 + scope 未挂载 = 404；授权撤销 + scope 已挂载 = 404；两者都满足 + 灰度开关关 = 该灰度特性不可见但组件可用（R88：未挂载的 404 在网关、SDK 入口、外壳三处都要验证，挂载 / 卸载经 S1-RT-005 的 `MountAsync` / `UnmountAsync`）
- [ ] E2E：未挂载组件的远程模块 `mf-manifest.json` 不被请求
