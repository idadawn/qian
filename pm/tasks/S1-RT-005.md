## 背景

平台插件 `Qian.Lifecycle`（`ctx.Lifecycle`）：平台级 `Install / Activate / Rollback / Deprecate / Retire`，租户级 `Provision / Upgrade / Uninstall / Purge`，`Mount / Unmount` 写租户 scope patch（取代 `Enable / Disable`）；钩子 `idempotencyKey = (tenant, plugin, hook, toVersion)` 入 `lifecycle_runs`；强制验签（OCI + cosign，声明式包 Ed25519，信任根经 Apollo `qian.common.trust`）；`IDeploymentExecutor` 的 `GitOps` 与 `Local` 两种实现；集成事件 `lifecycle.*.v1` / `registry.scope.*.v1`。

## 验收

- [x] E2E：参考应用在租户 A、B 分别 `Provision` 并挂载，`lifecycle_runs` 各有一条成功记录；对租户 A 重复执行 `Provision` 不产生副作用（幂等）
- [x] E2E：发布参考应用修订 n+1 并激活，租户 A 升级、租户 B 保持 n；对 A 回切到 n 后 A 的请求由修订 n 处理且数据可读（前向兼容）
- [x] IT：未签名制品与签名不匹配制品均 `Install` 失败；信任根轮换后旧签名在重叠期内有效
- [x] IT：`Mount(scope, entry)` 写入 `scope_patches` 并发出 `registry.scope.mounted.v1`；`Unmount` 后 ≤ 5s 三处拦截恢复，不改数据库开关
- [x] IT：`Mount(scope, entry)` 与 Registry scope Reconciler 对声明契约索引的组件强制套用 `OpenApiContractPlugin` / `GrpcContractPlugin`，破坏性契约的挂载为 Failed 且原因进入 `/api/lifecycle/diagnostics`（S1-RT-006 复核 R76）
- [x] IT：`GitOps` 执行器为 `runtime.form: service` 组件生成 Kustomize 片段并以 K8s 状态 + `/health` 双条件回写注册表（Local 执行器在开发态等价）
