## 背景

2026-11-11 产品负责人指示：「整个框架的话，起名叫 Yi，源自易经，包括基础框架 kun、qian、agent sdk 等。」

ADR-021 规定了 Kun / Qian / yue 的三层口径，产品族本身没有名字；它的备选方案里否决过「文档站改用产品族名」，理由是当时三个名字已经够用。总名定下后这一条要重新看。

D1 由产品负责人的指示直接决定。D2–D5 是主会话的推荐口径，产品负责人确认或改裁后写进 ADR-021。

- D1 总名（产品负责人 2026-11-11 指示）：整个框架叫 Yi，源自《易经》，包括基础框架 Kun、Qian、Agent SDK 等。
- D2 书写与定位。推荐：英文写 `Yi`，中文写「易」。Yi 是产品族的总称，不是第四层，也不新建仓库；ADR-021 D21.1 的三层口径（Kun 框架层、Qian 平台层、yue 前端层）与 D21.2「不建大单仓」不变。
- D3 涵盖范围。指示点名了 Kun、Qian 与 Agent SDK。推荐 yue 也算在内。iClaw 是否算在内待定：ADR-016 划了它与 Qian 的边界（iClaw 是 Agent 运行时与 AI 资产控制面），主会话倾向把它算作「基于 Yi 构建的产品」，不算 Yi 的组成部分。
- D4「Agent SDK」指什么。候选：现有的 `Qian.Plugin.Sdk` / `@qian/plugin-sdk` 与 Agent 就绪契约（PRD 7.18）；或另立一个面向 Agent 宿主的包族。待产品负责人说明。
- D5 改名范围。推荐只加总称：仓库名、包名（`Kun.*`、`Qian.*`、`@yue/*`）、命名空间与域名都不改。回写的地方是各仓库 README 的「产品族地图」、文档站首页与站名副标题、`AGENTS.md` 的三层口径一句。
