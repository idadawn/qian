## 背景

S1 实现 **待激活 → 试用 | 正常 → 宽限 → 冻结 / 恢复** 迁移，每次迁移发 `tenant.created/activated/suspended/resumed/expired.v1`；`POST /tenants/{id}:activate|suspend|resume`（幂等 + 审批钩子）；到期扫描作业由 7.13 调度器执行；会话中心订阅后吊销该租户会话；`GET /api/tenancy/meta/state-machine` 机器可读。只读 / 注销 / 数据销毁尾部为 S3。

## 验收

- [ ] IT：租户到期进入宽限后，该租户新登录被拒、已登录会话在 ≤ 60s 内失效（`tenant.expired.v1` → 会话吊销）
- [ ] E2E：7.3 租户到期扫描作业在 staging 准点触发并发出 `tenant.expired.v1`
- [ ] UT：非法迁移（如从注销回正常）返回结构化错误；`Suspend` 任一状态可进、`Resume` 回原状态
- [ ] UT：`suspend / purge` 能力标 `destructive` + `humanOnly`
