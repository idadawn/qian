## 背景

S1 实现 **待激活 → 试用 | 正常 → 宽限 → 冻结 / 恢复** 迁移，每次迁移发 `tenant.created/activated/suspended/resumed/expired.v1`；`POST /tenants/{id}:activate|suspend|resume`（幂等 + 审批钩子）；到期扫描作业由 7.13 调度器执行；会话中心订阅后吊销该租户会话；`GET /api/tenancy/meta/state-machine` 机器可读。只读 / 注销 / 数据销毁尾部为 S3。

## 验收

- [x] IT（R95 改写）：租户到期进入宽限时同事务经 Outbox 发出 `tenant.expired.v1`，该租户的业务入口（命令策略、能力目录）即时拒绝；「新登录被拒」归 S1-IDP-003，「已登录会话 ≤ 60s 内失效」归 S1-IDP-004（会话中心订阅 `tenant.expired.v1` / `tenant.suspended.v1`）
- [x] IT（R95 改写）：到期扫描是 `qian.tenancy` 的幂等能力（能力目录条目，供 7.13 调度器以 callback 类型调用，不标 `humanOnly`；R107 更正：按 R52 应为 `agent.expose: false`——不派生为模型工具、服务主体可调，契约修正归 S1-TEN-009）：进程内调用后到期租户进入宽限并发出 `tenant.expired.v1`，未到期租户不变，重复执行无副作用；调度器准点触发与 staging E2E 归 S1-SCH-002
- [x] UT：非法迁移（如从注销回正常）返回结构化错误；`Suspend` 任一状态可进、`Resume` 回原状态
- [x] UT：`suspend / purge` 能力标 `destructive` + `humanOnly`
