## 背景

ADR-020 D20.6 / D20.9：`skills/<name>/SKILL.md`、`agents/<name>.md`、`commands/<name>.md`、`hooks/hooks.json`、`.mcp.json` 五种表面加 `tools/`、`config/qian.patch.yml` 的解析器；每种一份 JSON Schema 2020-12 + 语义校验（`allowed-tools` 存在、hooks 引用的事件 / 能力存在、MCP 服务器名唯一、内联 shell 仅限人类 CLI 侧）；错误 = `ErrorDetail` + 文件路径 + 行号 + JSON Pointer；.NET 与 TS 跑同一组 fixture，供 `qian doctor`、CI、市场准入与 S4 共用。S1-M1 交付项。

## 验收

- [x] CI：校验器对 20 个坏样例（缺 front matter 字段、`allowed-tools` 引用不存在的工具、hooks 引用不存在的事件或能力、`.mcp.json` 格式错、`commands/` 内联 shell 出现在服务端 hook）逐一返回带文件路径与 JSON Pointer 的结构化错误
- [x] UT：五种表面各自的 JSON Schema 2020-12 与 fixture 在 .NET 与 TS 两侧结果一致
- [x] UT：`plugin.json` 的表面指针缺省指向约定目录、可覆盖；无 `src/` 的 skill-only 组件可被解析
