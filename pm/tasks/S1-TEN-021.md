## 背景

开通流程原型第 8 块：租户管理员首次进入企业控制台。外壳首页（租户会话）显示：
- 试用提示条：剩余天数与到期日，到期后进入宽限期的说明；
- 问候；
- 开通引导清单：管理员账号已完成，其余按真实数据判定完成与否，只链接到已存在的页面；
- 企业信息卡：租户号、状态、到期日、用户用量、管理员。

现在的首页是开发期的会话信息卡。

## 验收

- [x] 租户会话的首页按原型显示试用提示、开通引导与企业信息。数据来自真实接口：租户主档、配额用量、管理员；接口是租户主体只读本租户，不能读其它租户
- [x] IT：本租户摘要接口对租户主体只返回本租户，平台主体、其它租户主体与无凭据分别被拒
- [x] E2E：S1-TEN-020 主线里申请人首次登录后看到试用提示（剩余天数与到期日一致）与开通引导；正式租户不显示试用提示；原首页的会话与权限信息仍可在页面内查到，`pnpm yue:auth` 既有用例随之调整后通过
