## 背景

按 S1-DEC-004 建立同组织独立私有仓库，布局 `plugins/<domain>/<id>/`，S1 收录全部平台插件、参考应用与至少一个 skill-only 示例组件；CI：每个条目过校验器 + `qian add` 到 `minimal` profile 的 smoke；目录网站静态生成（分类、安装命令、README 渲染、校验状态徽章）；GitHub topic `qian-plugin` 社区发现只发现不信任，安装需 `--trust`。

## 验收

- [ ] CI：官方市场仓库每个条目指向的组件通过五种表面校验器与清单校验零错误；`qian add` 每个条目到 `minimal` profile 的 smoke 全部通过
- [ ] E2E：目录网站由 marketplace.json 一条命令生成，条目数、分类与仓库一致，每个条目显示校验状态徽章
- [ ] IT：经 GitHub topic 发现的社区组件标记「未验证」，`qian add` 该组件在无 `--trust` 时拒绝并说明原因
- [ ] 检查：仓库收录全部 `platform` base 组合包平台插件、参考应用与一个 skill-only 示例
