## 背景

补充裁决 S1 必做、迁移顺序第 4 波：网页扫码 + 工作台 UA 识别免登，code 换 userId，多租户先反查 openid 绑定的租户；租户级启停 = 在租户 scope 挂载 / 不挂载其配置条目，被过滤的连接器在登录页与回调路由两处与不存在无法区分；不照搬 JWT 自动续签头与 query token。钉钉 / 飞书为 S2。

- [ ] E2E：企业微信扫码登录与企微工作台内免登在 staging 走通；同一企微账号在两个租户分别绑定不同 Membership
