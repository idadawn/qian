## 背景

S1-DEC-033 D5 的页面部分。管理后台目前只有平台运营一侧的页面（租户管理、开通申请），租户管理员登录后没有任何管理页面。

本任务交付成员管理页，作为租户 scope 的远程页面经外壳按需加载。做法照租户运营页面（`packages/qian-tenancy-ui`）：由 HTTP 契约生成客户端，用 yue 组件，UI 清单声明菜单与所需权限。产品负责人 2026-11-11 确认成员管理按推荐范围提前（R145）。页面并入身份组件的 UI 表面还是另立组件，这次没有定：开工时给出推荐并向产品负责人确认，不自行决定。

角色授权页在 S1-AZ-005。本页只在成员详情里显示已有角色，不做授予。

## 验收

- [ ] E2E（联调环境真实栈）：租户管理员在导航里看到「成员管理」，列表显示本租户成员（姓名、账号、状态、主归属），可按组织筛选与搜索
- [ ] E2E：新增成员（新建账号与绑定已有自然人两条路径）后列表出现该成员，新成员能登录；配额已满时页面显示结构化错误
- [ ] E2E：启用 / 禁用成员、调整组织与岗位归属（用 `OrganizeSelect` 等业务选择器）后刷新仍在；禁用后该成员不能登录
- [ ] 普通成员的导航里没有该菜单，直接访问页面与接口被拒；平台控制台不出现该页
- [ ] `pnpm yue:gates` 通过，页面有视觉基线与中英文文案，契约生成物无漂移
- [ ] 企业首页开通引导的「添加成员」一步配「去添加」按钮，进入成员管理页（R149：S1-YUE-019 偏离 12；`apps/qian-shell/src/welcome.tsx` 只给已有页面配按钮）
