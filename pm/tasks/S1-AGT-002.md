## 背景

7.18 第 5、6、11 项：能力条目 Agent 字段（`sideEffect: read|write|external|destructive`、`policyHint`、`idempotent`、`async`、`requiredScopes`、`requiredSecrets`、`dataClassification`、`costTier`、`contractVersion`、`schemaSha256`、`agent.expose / requiresConfirmation`）S1 全部落库不派生；清单 `permissions.platform/data/egress/secrets/ui` 落库（租户管理员批准 S1 API、S2 UI）；`inputSchema` 禁 tenant 字段的清单校验与契约 lint；OpenAPI 3.1 + `operationId`。

- [x] UT：清单 `permissions.*` 五类落库并可经 API 读取；安装时需租户管理员批准的 API 存在
