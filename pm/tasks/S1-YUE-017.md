## 背景

产品负责人 2026-10-20 指出现有样式难看，2026-11-03 要求在按开通流程原型开发的同时优化前端组件样式（S1-DEC-032）。原型画板用的都是 `@idadawn/yue-tokens` 的语义色。问题不在色板，而在组件的组合与细节：
- 徽标没有状态圆点；
- 页签只有胶囊样式；
- 数据表没有卡片容器，分页松散；
- 抽屉内容与按钮堆在一起，没有固定页脚；
- 外壳侧栏每一项都画箭头、没有图标；
- 用户入口只是一段文字；
- 图标只有 14 个；
- 没有步骤条。

本任务在 yue 层统一调整，页面任务（S1-TEN-018 / 020 / 021、S1-YUE-018）只消费组件，不各自打补丁。规格见 `docs/prd/specs/tenant-signup.md` §9。

## 验收

- [x] 令牌：新增应用画布底色语义令牌（浅色为略带蓝调的浅灰，深色同步），外壳主区与页面用它；registry 与生成物一致，`tokens:check` 通过
- [x] 组件：
  - `Badge` 增加带圆点的样式（五种 tone）；
  - `TabsList` / `TabsTab` 增加下划线样式（可带计数）；
  - `DataTable` 有卡片容器、表头底色与分页布局（共 N 条、每页条数、页码）；
  - `Sheet` 分出页头 / 可滚动主体 / 固定页脚，可设宽度；`useDrawer` 的抽屉用这套布局，表单按钮进页脚；
  - `PageHeader` 支持面包屑与操作区；
  - 新增 `Steps` 步骤条（完成 / 当前 / 失败 / 待办，键盘与 ARIA 齐全）；
  - `Icon` 补齐外壳与页面常用图标。

  每个新组件或新样式都带 `data-slot` / 默认 `data-testid`、browser 用例（axe critical / serious = 0）与 SSR 用例，并在文档站登记场景
- [x] 外壳 `AppShell`：品牌标识、带图标的导航项（不再统一画箭头）、当前项高亮、可选分组标题、底部用户卡片；收起状态与跳到主内容链接保持可用。yue-playground 门禁（a11y、Lighthouse）通过
- [x] 视觉基线：受影响的截图用 `pnpm yue:visual --update-snapshots=all` 重新生成，逐张审阅后提交，`pnpm yue:visual` 在未更新模式下通过；`pnpm yue:gates` 全链通过，changeset 已加
