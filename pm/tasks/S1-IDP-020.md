## 背景

S1-YUE-019 偏离 4、15（R149）：
- 选择工作空间的候选不带租户状态。候选来自 `/api/identity/login` 与 `/session/switch` 返回的 `SignInView`。原型给每张卡片标企业状态与试用剩余天数，冻结的企业不可进入并说明原因。
- `AuthTenant` 还没有逐项状态与禁用字段，要和接口一起加。R147 缺陷 7 已更正此前「卡片组件已支持禁用态」的说法。
- 选择页顶栏现在是「返回登录」，只回到登录页，账号会话还在。身份服务没有结束账号会话的端点，所以做不出原型的「退出登录」。原型副标题里的账号标识也没有放。

外壳退出时不结束发行方会话，这个问题记在 S1-IDP-016；本任务只管选择页上的账号会话。两处如果共用同一个登出端点，开工时与 S1-IDP-016 对齐。

## 验收

- [ ] 接口：工作空间候选每项带租户状态（`trial` / `active` / `grace` / `suspended`，与租户管理同一口径）与有效期；契约与生成物同步，旧客户端忽略新字段不受影响
- [ ] yue：`AuthTenant` 增加状态字段；冻结（`suspended`）的卡片不可进入并说明原因，试用与宽限期显示剩余天数；有 browser 用例（axe critical / serious = 0）、SSR 用例与文档站场景
- [ ] 服务端同样拒绝选择冻结的租户（已有校验的补用例），错误与页面说明一致
- [ ] 账号会话登出端点：选择页顶栏「退出登录」结束账号会话并回到登录页，浏览器后退或重放选择请求都不能再进入；副标题显示掩码后的账号
- [ ] E2E（联调栈）：冻结一个租户后，其成员在选择页看到不可进入的卡片与原因，其余工作空间照常进入；退出登录后须重新输入密码；`pnpm yue:gates`、`pnpm yue:auth` 通过
