## 背景

平台插件 `Qian.Capabilities`（`ctx.Capabilities`）：`ICapabilityRegistry` 收 `JsonTypeInfo` 生成请求 / 响应 Schema；`GET /api/capabilities?kind=&q=` 按权限与 scope restrict 过滤（`ttlMs`、`cacheScope: private`）；`GET /api/capabilities/openapi.json` 聚合 OpenAPI 3.1；`IContractRepository`（`.proto` / OpenAPI 契约包带 `/vN`，挂载前契约一致性探测）；扩展点按 ADR-020 D20.3 和组件规格 §3.6 使用事件定义及可逆服务注册；菜单由清单贡献 + URN 目录 + 用户偏好（`qian.navigation` 逻辑名）；`/api/kernel/capabilities` 别名。

## 验收

- [x] IT：`GET /api/capabilities` 对无权限用户不返回其不可调用的能力，对被租户 scope `restrict` 掉的能力同样不返回；响应含 `cacheScope: private`
- [x] IT：v1 别名 `GET /api/kernel/capabilities` 与 `/api/kernel/capabilities/openapi.json` 返回同一结果并带 `Deprecation` 与 `Link: <后继路径>; rel="successor-version"` 响应头（R33；Link 由 S1-RT-019 补齐并断言头值）
- [x] IT：`GET /api/capabilities/openapi.json` 需认证并只聚合已挂载组件；契约准入机制完成——`OpenApiContractPlugin` / `GrpcContractPlugin` 在业务 Apply 前拒绝契约不兼容（OpenAPI diff / proto 破坏性）的组件；平台挂载路径（`Mount` 与 Registry scope Reconciler）的强制准入归 S1-RT-005（R76）
- [x] UT：注册一个命令后目录出现其 ID、JSON Schema 与 Agent 字段（`sideEffect / policyHint / requiredScopes / schemaSha256`）
- [x] IT：菜单贡献可按租户 scope 遮蔽；未挂载组件的菜单项不出现（404 语义）
