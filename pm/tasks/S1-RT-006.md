## 背景

平台插件 `Qian.Capabilities`（`ctx.Capabilities`）：`ICapabilityRegistry` 收 `JsonTypeInfo` 生成请求 / 响应 Schema；`GET /api/capabilities?kind=&q=` 按权限与 scope restrict 过滤（`ttlMs`、`cacheScope: private`）；`GET /api/capabilities/openapi.json` 聚合 OpenAPI 3.1；`IExtensionPointRegistry` / `IContractRepository`（`.proto` / OpenAPI 契约包带 `/vN`，挂载前契约一致性探测）；菜单由清单贡献 + URN 目录 + 用户偏好（`qian.navigation` 逻辑名）；`/api/kernel/capabilities` 别名。

## 验收

- [ ] IT：`GET /api/capabilities` 对无权限用户不返回其不可调用的能力，对被租户 scope `restrict` 掉的能力同样不返回；响应含 `cacheScope: private`
- [ ] IT：v1 别名 `GET /api/kernel/capabilities` 返回同一结果并带 `Deprecation` 响应头（R33）
- [ ] IT：`GET /api/capabilities/openapi.json` 需认证并只聚合已挂载组件；挂载一个契约不兼容（OpenAPI diff 破坏性）的组件被拒绝
- [ ] UT：注册一个命令后目录出现其 ID、JSON Schema 与 Agent 字段（`sideEffect / policyHint / requiredScopes / schemaSha256`）
- [ ] IT：菜单贡献可按租户 scope 遮蔽；未挂载组件的菜单项不出现（404 语义）
