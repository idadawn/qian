## 背景

只保留一套表单 / 表格 / 弹层引擎：Field + react-hook-form + Ajv；SchemaForm 基础版 + API 式 `FormApi`；`dependencies` 基础联动；编辑 / 只读态引擎级统一；校验与脱敏规则目录；`useModal / useDrawer / usePopup`；Message / Confirm 统一出口；元数据契约草案：控件 manifest、FormSchema / ListSchema 含 `device`、`auth`、权限码目录格式（第 3 波冻结输入）。

## 验收

- [x] E2E（R108 改写）：在靶场（`apps/yue-playground`）用 SchemaForm 完成新增 / 编辑弹层、只读详情与提交，请求经 `@yue/sdk` 的 mock 中间件，不出现第二套表单实现；参考应用版本归 S1-QA-007 验收 2，真实后端上的 SchemaForm + DataTable CRUD 由 S1-TEN-005 承担
- [x] UT：控件 manifest 与 FormSchema / ListSchema 草案通过各自 JSON Schema 校验，`device`、`auth` 字段存在
- [x] UT：编辑态与只读态由同一引擎渲染；`dependencies` 联动用例通过
- [x] UT：校验与脱敏规则目录可导出 JSON
