## 背景

只保留一套表单 / 表格 / 弹层引擎：Field + react-hook-form + Ajv；SchemaForm 基础版 + API 式 `FormApi`；`dependencies` 基础联动；编辑 / 只读态引擎级统一；校验与脱敏规则目录；`useModal / useDrawer / usePopup`；Message / Confirm 统一出口；元数据契约草案：控件 manifest、FormSchema / ListSchema 含 `device`、`auth`、权限码目录格式（第 3 波冻结输入）。

## 验收

- [ ] E2E：用 SchemaForm + DataTable 实现参考应用的客户 CRUD（新增 / 编辑弹窗、只读详情），不出现第二套表单实现

- [ ] UT：编辑态与只读态由同一引擎渲染；`dependencies` 联动用例通过
- [ ] UT：校验与脱敏规则目录可导出 JSON
