## 背景

组件 `qian.entitlement`（`Qian.Entitlement.Abstractions` / `ctx.Entitlement` + `Qian.Entitlement`）：`tenant_entitlements`（tenant、plugin、version_range、plan_id 可空、source `manual | plan | order`、valid_from/to、status、granted_by）；`PUT/DELETE /api/tenants/{id}/entitlements/{plugin}`、`GET /api/entitlements/me?plugin=`（返回 `{ entitled, versionRange, validTo, features[], seats, meters }` S3 字段可空）；Redis `ent:{tenant}:{plugin}` TTL 5 分钟 + `entitlement.changed.v1` 失效；授予 → `qian.lifecycle` 的 `Entitled`；平台插件（`policy.required: true`）恒授权。「开没开」由 scope patch 表达，本组件只答「买没买」。权益 API 形状是 S3 市场几乎改不了的三件事之一。

## 验收

- [ ] IT：`IsEntitled` 对平台插件恒 true；对过期授权（`valid_to` 已过）返回 false 并发事件
- [ ] UT：权益响应 Schema 含 S3 预留字段（可空），契约快照测试锁定形状
- [ ] IT：授予 / 撤销写审计并发 `entitlement.changed.v1`，缓存 ≤ 5s 失效
- [ ] UT：`entitlements.me` 标 `read`；授予 / 撤销标 `write` + `confirm`
