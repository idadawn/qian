## 背景

ADR-020 D20.8：`.qian/marketplace.json`（`name`、`interface.displayName`、`plugins[]`，条目 `name` / `source`（local / url / git-subdir）/ `policy`（`installation`、`authentication: ON_INSTALL | ON_USE`、`profiles[]`）/ `category` / `interface`）的 JSON Schema 与条目校验器（指向的组件须过表面校验器与验签要求）；本机 `.qian/marketplaces.json` 多市场登记、按顺序解析、同名组件按优先级并写入 `lock.json`；`ON_USE` 条目在 S1 只登记并提示。

## 验收

- [x] UT：marketplace.json 示例通过 JSON Schema 校验；条目指向未过校验器的组件时校验器报错
- [x] E2E：登记第二个（租户私有）市场后 `qian list --remote` 合并两处结果并标注来源；同名组件按市场优先级解析并在 `lock.json` 记录来源
- [x] UT：`@version` 解析为 git tag（声明式）与 NuGet / npm 版本（代码部分）

## 验收证据

- marketplace/v2 入库；.NET 与 TS 共用市场结构/跨字段向量，错误码、文件、指针、行号与级别逐字段一致；沿用组件校验器，错误组件不能进入解析结果。
- 实际 CLI 登记第二市场后合并远程列表，展示来源与优先级；同名首选经无代码安装切片写入 lock，包含市场、source、digest、公钥指纹及可用 commit。confirm、ON_USE、restricted 和未验证 community/no-code 边界均显式处理。
- 实际 Git 仓库/标签测试确认 @version 选择 refs/tags/v<version>，NuGet/npm 精确版本取自所选清单；分支缺 digest、归档损坏、验签失败、公钥撤销、链接、越界和凭据 URL 被拒绝。
- 代码包安装/升级/移除、租户 scope 与进程中断后的完整恢复仍归 S1-RT-011；本任务只交付解析验证与真实无代码来源锁定，不宣称依赖包已安装。
