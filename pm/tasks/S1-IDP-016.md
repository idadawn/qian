## 背景

S1-YUE-002 验收复核（2026-10-23）里 .NET 侧独立审读核实出的非阻断问题与用例盲区，都在 qian.identity / Identity.Client 的产品代码上，归本任务：

- 任意发行方模式（Resource 为空，Identity.Client README 仍称支持）：`GET /auth/session` 恒 401（`IdentityClientCurrentUser.PrincipalKey` 只由规范模式的处理器写入，外壳会无限跳登录）、`POST /auth/session/refresh` 先轮换 refresh token 再在 `IdentityPrincipals.cs:122` 抛错——Resource 为空时不映射这两个端点并在 README 标注，或补齐该模式。
- 刷新成功但新访问令牌投影失败（`packages/Qian.Identity.Client/IdentityClientEndpoints.cs:80-85`）：只删 Cookie 不删服务端会话（带着刚轮换的令牌留到 TTL），发行方元数据瞬时不可用时投影也返回 null、被当成会话结束，瞬时故障就把用户强制登出——把「瞬时错误」与「令牌不符」分开：前者不结束会话（503 或保留快照），后者删会话 + Cookie；两处删 Cookie（`:83` 与 `IdentitySessions.cs:78`）互为冗余。
- 未兑换的切换 / 选择票据躲过会话吊销与改密（`IdentityAccountService.SignIn.cs:127-142,471`；票据 ≤ 5 分钟）：兑换时不复核来源会话是否仍有效，吊销 / 强制下线 / 改密都不作废未兑换票据，与 ADR-005 D5.4 及「改密使全部会话失效」矛盾（IDP-003 既有缺陷，S1-YUE-002 把 switch 接上了产品路径）——EstablishAsync 替换会话时核验来源会话，吊销与改密时作废此人全部未兑换票据；选择票据不绑浏览器（连接器流程绑了 `qian.identity.browser`），评估同样绑定。
- id_token 下发标准 `name`（R129 ③）与 ADR-005 D5.9「令牌只含身份、预留 profile」口径：name 不看 scope、对所有客户端下发，profile 也没有登记成 scope——在 ADR-005 补记，并在 S3 第三方客户端接入前决定是否改为 profile scope。
- PathBase：选择页 302 不带 PathBase（`IdentityProtocolEndpoints.cs:81`）而 return_url（`:249`）与连接器落点带；认证页族入口只认 pathname 恰好 `/connect/authorize`——统一并补 `UsePathBase` 用例。
- 其它：依赖方快照的 displayName 刷新后不更新（Kun 只在登录时取 id_token 的 name）；选择页停留计入 RP 登录事务的 5 分钟（超时回调 422、身份侧已切换）；外壳退出不结束发行方会话（Identity.Client README 既有口径，与 ADR-005 D5.4 后通道登出双向有落差，E2E 第 8 步依赖它）；强制刷新无节流（每次都是一次 refresh_token 授权 + 账号库校验 + 轮换）；`IdentityProtocolEndpoints.cs:55` 不可达分支、`AccountValidation` 双 summary、`IdentityAccountOptions.IsLocalPath` 与 Identity.Client 重复、JIT 开户显示名不拦 Cf 格式字符——各自决定改或登记理由。
- 用例盲区（推演，未实跑）：prompt 白名单 Theory（consent / create / `select_account consent` / `select_account login` / `SELECT_ACCOUNT` / 重复参数 / none）；无账号模型宿主遇 `select_account` 应 interaction_required；吊销会话或停用成员遇 `select_account` 先登出再挑战、ReturnUrl 无 prompt、账号 Cookie 被清；换码 / 刷新时 `ReplaceName`（改名后 refresh 用新名且只有一个 name）；平台身份快照显式 `null`（`DefaultIgnoreCondition`）；强制刷新的已认证守卫（访问令牌换成无效值 → 401 且发行方刷新计数不变）；`IsLocalPath` 反斜杠 / 控制字符 InlineData；两路并发强制刷新只换新一次（S1-YUE-002 复核突变 N04 存活）。

## 验收

- [ ] Resource 为空的宿主：两个会话端点要么不映射（README 标注）要么可用——有用例
- [ ] 刷新成功但投影失败：令牌不符 → 401 + 删会话 + 删 Cookie；发行方元数据瞬时不可用 → 不结束会话——两条各有失败用例
- [ ] 来源会话已吊销 / 已改密后兑换票据被拒；吊销与改密作废未兑换票据——有失败用例
- [ ] ADR-005 补记 name claim 口径；PathBase 统一并有 `UsePathBase` 用例
