## 背景

组件 `qian.scheduler`（`Qian.Scheduler.Abstractions` / `ctx.Scheduler` + `Qian.Scheduler`）：`job_definitions` / `job_triggers` / `job_runs`；cron 6/7 段、固定间隔、一次性延时；多租户命名空间；每副本每秒 `FOR UPDATE SKIP LOCKED` 领取到期触发器 + 租约；misfire、并发策略与超时；`Cancel(businessKey)`；`local` 任务类型 `[QianJob("code")]`；`IScheduler.ScheduleOnce / ScheduleCron / Cancel`。7.3 到期扫描、7.4 密码提醒、7.12 重试、7.11 链校验的公共前提。

## 验收

- [x] IT：3 个副本运行、100 个每分钟触发器，每分钟恰 100 次执行无重复（`job_runs` 按 trigger × 分钟唯一）
- [x] IT：杀掉正在执行的副本，租约到期后触发器被另一副本接管并按 misfire 策略处理
- [x] IT：`ScheduleOnce(businessKey)` 后 `Cancel(businessKey)`，到点不执行；重复 `ScheduleOnce` 同一业务键只保留一条
- [x] UT：作业定义 Schema 机器可读；目标必须是能力目录中的 URI，任意 URL 被拒

- [x] IT：执行副本续租失败时不完成或归档一次性任务，租约到期后另一个副本使用同一 run 接管；显式 Cancel、超时重试与正常停止行为保持通过
