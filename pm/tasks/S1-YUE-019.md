## 背景

2026-11-11 产品负责人要求按开通流程原型（Design 画布 <https://claude.ai/artifact/6ktBwDv8v145iJB9DiSy84>）把页面 1:1 复刻出来，基础组件不满足就优化基础组件。S1-YUE-017 与 S1-TEN-018–021 按原型刷新过样式，但页面与原型仍有成片差异：
- 登录页没有深色品牌侧栏；
- 注册页先单独核验手机号，再展开表单；
- 进度页是三步，按钮靠右；
- 选择工作空间只有一列按钮；
- 开通申请的页签顺序、行内操作与审核抽屉排版不同；
- 租户管理的行内操作没有收进「更多」；
- 企业首页下面还挂着会话、权限与页面卡片；
- 外壳顶栏多了侧栏开关与语言按钮，没有面包屑与工作区卡片。

原型的颜色全部取自 `@idadawn/yue-tokens` 色阶，差异在组件的尺寸、圆角、字重、组合与少量缺失的样式。本任务先在 yue 层补齐，再逐页复刻；页面只消费组件，不各自打补丁。原型里依赖后端新能力的元素不做假入口，列在进度日志里另立任务。

## 验收

- [ ] 令牌与基础组件：
  - 画布改为原型的冷灰；语气色补齐底色、边框、文字、实心四档，徽标、提示、标签与导航当前项共用；卡片圆角 12px。
  - `Button` 增加 40 / 44px 两档尺寸与主色浅底按钮，主按钮加粗，描边按钮用原型边框色。
  - 输入框与 SchemaForm 控件有尺寸档；标签 13px 并带必填星号，说明 12px。
  - `Segmented` 等分铺满；`TabsTab` 支持胶囊计数；`Steps` 支持深色底；`Tag` 支持圆点；`Descriptions` 支持整行项。
  - `DataTable` 的「显示列」可关、可排在工具行尾部插槽之前，行内边距与分页分隔与原型一致。
  - 新组件或新样式都带 `data-slot` / 默认 `data-testid`、browser 用例（axe critical / serious = 0）与 SSR 用例，并在文档站登记场景。
- [ ] 外壳与认证页族：
  - `AppShell` 侧栏 232px，带工作区卡片与实心导航角标；顶栏为面包屑加帮助、通知、主题，侧栏收起入口移到品牌行，语言移进用户菜单。
  - 新增深色品牌侧栏的认证页布局；密码登录为 44px 表单，带「记住账号」。
  - 选择工作空间为卡片列表：图标块、租户号 · 角色、不可进入态、虚线的申请开通入口。
- [ ] 页面逐块对照原型复刻：登录、注册并申请开通、申请进度、选择工作空间、开通申请列表、审核抽屉、租户管理、企业首页。布局、尺寸、文案与颜色一致；截图与原型并排比对，结论记在进度日志。
- [ ] 原型里需要后端新能力的元素不做假入口，逐条列在进度日志，由产品负责人决定是否另立任务。
- [ ] 门禁：
  - `pnpm yue:gates` 全链通过；
  - `pnpm yue:auth`、租户运营页 E2E 与 `pnpm yue:mf` 通过；
  - 受影响的视觉基线逐张审阅后更新，未更新模式下 `pnpm yue:visual` 通过；
  - 已加 changeset。
