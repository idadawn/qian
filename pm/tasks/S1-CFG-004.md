## 背景

OpenFeature 式 `IFeatureFlags.IsEnabled(name, tenantId)`，namespace `qian.common.flags`，键 `flag.<name>` 值为规则 JSON（默认、租户白名单 / 百分比）；只管灰度放量，与 7.14 授权（买没买）、租户 scope 挂载（开没开）分开存（ADR-014 / ADR-020 D20.5）；`flags.set` 标 `write` + `confirm`。

## 验收

- [x] IT：`IFeatureFlags` 对白名单租户返回 true、其他租户 false；与 7.14 授权结果、租户 scope 挂载状态互不影响
- [x] UT：百分比规则对同一租户稳定（同 key 多次求值结果一致）
- [x] UT：`flags.set` 能力元数据标 `write` + `confirm`
- [x] IT（S1-DEC-031 A）：可选 `qian.config.flags` 管理组件经受限 Portal OpenAPI 保存规则草稿，明确返回待发布且不调用发布接口；人工发布后真实配置源才更新求值。验证平台权限、固定目标边界、secretRef、缺写端拒绝与脱敏审计；不得用 AdminService 绕过授权或用假写端替代真实验收
