## 背景

组件 `qian.audit`（`Qian.Audit.Abstractions` / `ctx.Audit` + `Qian.Audit`，随 SDK 进每个 .NET profile）：`audit_entries`（tenant_id、seq、prev_hash、content_hash UNIQUE、actor_type ∈ user | service | agent、on_behalf_of、capability_id、contract_version、input_hash、channel ∈ ui | api | mcp | a2a | job | event、resource、result、trace_id、payload）与 `audit_chain_state`（按租户一条链 + 平台链，`SERIALIZABLE` 读 tip 更新、冲突重试）；`content_hash = SHA256(prev_hash || canonical_json(entry))`；Mediator `AuditBehavior` 读 `[Capability(Audit = true)]`，命令默认记录、查询 opt-in，记输入哈希并按 Schema `sensitive` 脱敏；作为 base 组合包的 `waterfall` 监听器，卸载即逆序撤销；`IAuditWriter`。
