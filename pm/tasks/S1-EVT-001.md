## 背景

组件 `qian.events`（`Qian.Events.Abstractions` / `ctx.Events` + `Qian.Events`，随 SDK 进每个 .NET profile）：`QianEventEnvelope { version, event_id (uuid v7), subject, type, occurred_at, tenant_id, producer, correlation_id?, causation_id?, actor { kind, id, on_behalf_of? }, trace_parent, payload }` 对齐 iClaw 契约；`[IntegrationEventId]` 稳定 ID 与 payload Schema 导出；`Publish` 只允许命令 handler 同 scope；Outbox 发布器批 100、`FOR UPDATE SKIP LOCKED`、publisher confirm、指数退避；exchange `qian.events`（topic）、quorum 队列 `q.<service>.<subscription>`、广播队列；独立模式 Outbox 用宿主 DbContext。与 `Qian.Runtime` 进程内事件不混用。

## 验收

- [ ] IT：参考应用创建客户后 `outbox_messages` +1，RabbitMQ 收到 1 条
- [ ] IT：杀掉发布器副本后另一副本接管，无重复发布（confirm 计数 = Outbox 行数）
- [ ] UT：信封通过 iClaw `events-schema.json` 校验；每个 `[IntegrationEventId]` 都能导出 JSON Schema
- [ ] UT：在非命令 handler 处 `Publish` 触发分析器错误；`actor.kind` 支持 `agent`
