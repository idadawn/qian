## 背景

ADR-020 D20.8：`qian add <component>[@version]` 从已登记市场解析条目 → 取组件文件夹 → 过校验器与验签 → 表面复制到 `.qian/<id>/` → `dotnet add package` / npm 安装 → 向当前 profile 的 `config/qian.patch.yml`（standalone 为 `.qian/patch.yml`）追加条目 → `qian doctor`；`--yes` / `--profile` / `--scope tenant:<id>`；`.qian/lock.json` 记来源与 digest / commit；`qian remove`、`qian list [--remote]`；子命令带 `--json`；Node 实现 + `dotnet qian` 薄包装。

## 验收

- [ ] E2E：空白 ASP.NET Core 项目执行 `qian add identity authz files`，表面进入 `.qian/`、NuGet 依赖按市场条目钉版、patch 条目写入、`lock.json` 记录 digest
- [ ] IT：`qian remove` 逆序撤销 `add` 的全部改动；`qian list` 列出本地已装组件及来源市场
- [ ] IT：未通过校验器或验签的组件 `add` 失败并输出结构化错误（`--json`）
- [ ] IT：`qian add --scope tenant:<id>` 写租户 scope patch，需平台连接与运营权限，S1 仅运营 CLI
