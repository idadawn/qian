## 背景

`plugins/qian.identity.client` 的 `runtime` 已由代码派生（S1-RT-033 的入口 `IdentityClientComponent`），S1-IDP-014 又以 CI 的 NativeAOT 冒烟为据声明了 `x-aot`；清单仍带 `x-skeleton`，因为 `qian add identity` 还差私有源发布与钉版。发版工作流 `dotnet-release` 只能从 main 手动触发，并锁步发布整个包族（同一版本只能发一次，包随公开仓库可见），所以这一步要等 IDP-014 合入 main 之后，另开一个 PR 交付。做法同 S1-RT-011 对 Data / Events / Config 的钉版与回验。

## 验收

- [x] 发布：IDP-014 合入后从 main 触发 `dotnet-release`，锁步发布一个包源里还没有的新版本；`Qian.Identity.Client` 能从私有源还原
- [x] 清单：`runtime.nuget` 钉 `Qian.Identity.Client` 的版本与归档 sha256 摘要，去掉 `x-skeleton`；`ClientManifestTests` 改为断言没有骨架标记；Profiles 测试与 `profiles.test.mjs` 的骨架警告数、`docs/generated` 同步
- [x] E2E：私有源 E2E（`packages/qian-cli/test/private-feed.e2e.mjs`）加入 identity。`qian add identity` 后表面进 `.qian`，NuGet 按清单钉版且只从私有源还原，lock 记录摘要；宿主按清单入口挂载组件，组件就绪；`qian remove` 逆序撤销
- [x] 文档：`plugins/qian.identity.client/README.md` 第四问与包 README「已知限制」改为已可安装
