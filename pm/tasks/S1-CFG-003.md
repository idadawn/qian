## 背景

`ValidatedOptionsMonitor<T>` 变更先跑校验器，失败保留上一份并计数 `qian_config_reload_failed_total`、发 `config.reload.failed.v1`；插件 `config.schema`（JSON Schema 2020-12）→ CI 生成 Apollo namespace 骨架并比对线上键、options JSON Schema 导出、`GET /api/config/schemas/{plugin}`；`dump-config` 条目 `config` 按此 schema 校验（7.2.1）；Apollo 发布事件进审计。
