## 背景

`docs/generated/` 在 main（e98422299）上已与源码派生结果不一致：S1-EVT-001（[idadawn/qian#73](https://github.com/idadawn/qian/pull/73)，提交 8e983747a）改了 qian.events 的配置 Schema、在 platform profile 里加了 Events seam，并让 `CommandPipeline.cs` 的生产方行号移位，但没有重新生成。重新运行 `pnpm exec qian docs generate --profile platform` 会改写 config-catalog、event-graph、seam-graph 三份文件。documentation 工作流每次都会生成这些文件，但只上传、不比对，所以漂移没有被拦下。

G2 文档新鲜度（ADR-020 D20.9、组件模型规格 §10.3、PRD §14 C18「漂移即失败、PR 阻断」）是已拍板的门禁，不是新设计；它原本排在 S1-QA-006，与 README / AGENTS.md 必需节、第二份清单、plugin.json 派生字段三项门禁一起。本任务只拆出 docs/generated 的新鲜度比对，其余三项仍归 S1-QA-006。

接入前已核实生成结果是确定的：同一组输入下，本机 macOS 的输出与 CI 运行 38454069285（Linux，4a0aaed2f）上传的产物逐字节一致，连续两次生成结果相同。
