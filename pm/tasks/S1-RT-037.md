## 背景

S1-AGT-006 验收复核（2026-10-23，done）留下的非阻断项，都在 qian.lifecycle 的审计接线上。ADR-009 D9.8 要求「插件生命周期操作」与「反向权限批准」都入审计：批准已由 S1-AGT-006 接通（`LifecycleController.Approvals.cs`，与批准记录同一可串行化事务经 `AppendEnlistedAsync` 写入租户审计链），生命周期操作本身（安装、激活、开通、升级、回滚、卸载）仍不写审计，`pm/tasks` 里没有承接。另外两处与同一接线相关：Lifecycle 对 Audit 的依赖没有在清单声明；缺审计时静默 404。

## 验收

- [x] IT：安装 / 激活 / 开通 / 升级 / 回滚 / 卸载各写一条租户审计链条目（平台级操作记平台链或目标租户链，口径在 README 写明），与状态变更同一事务，提交失败两者都不留；重试、续跑不重复记
- [x] 清单：`plugins/qian.lifecycle/.qian-plugin/plugin.json` 以 `optionalInject` 声明对 Audit seam 的依赖（`LifecyclePlugin` 同步），seam 图与装配完整性校验能看到 Lifecycle → Audit；Authz 旁路的同类先例一并补
- [x] 缺审计时的 404（`LifecycleController.Approvals.cs` 取不到 `IAuditService`）记一条宿主级日志，或进诊断端点，让宿主装配错误与无权限可区分；README 写明口径
- [x] UT：开通续跑用例在两次尝试之间激活另一版本，区分「按 TargetVersion」与「按 Active 修订」核对批准
