## 背景

三套 TCK 之三：清单校验、契约兼容性（OpenAPI diff / proto breaking / AsyncAPI）、生命周期钩子幂等（同一租户执行两次）、跨租户越权探测（以 A 的令牌读 B 的记录必须 404 / 403，7.3 渗透样例）、写命令 Schema 存在、`inputSchema` 禁租户字段、写能力带 `idempotencyKey` / `sideEffect` / 意图式 `description`、性能基线（P1）。`platform` base 组合包内全部插件 TCK 100% 是退出可测项。

## 验收

- [ ] TCK：参考应用每个写能力都有 JSON Schema、`idempotencyKey`、`sideEffect` 与意图式 `description`；缺一不过
- [ ] TCK：跨租户越权探测——两个租户，以 A 的令牌读 B 的记录必须 404 / 403
- [ ] TCK：生命周期钩子对同一租户执行两次无副作用；契约破坏性变更被 OpenAPI diff / proto breaking 拦截
- [ ] 检查：`platform` profile base 组合包内全部平台插件 TCK 通过率 100%
