## 背景

S1-TEN-005 验收复核（2026-10-22，done 维持）留下的非阻断建议。三条验收都成立，下列各项不影响「页面可用」，但缺回归保护或会误导使用者。

不在本任务：
- 契约 v2 才能改的三项只记入 v2 备忘：`TenantList.total` 收紧为必填整数；状态机 `action` 枚举化；名称长度统一按码点或 UTF-16 计（DEC-025 已接受现状）。
- `contracts.ts` 里 `$ref` 解引用和 requestBody → FormSchema 的适配，等出现第二个 ui 表面时再下沉到 `@yue/form`。

## 验收

- [ ] E2E 补测（R112：删掉被测行为，用例须失败）：
  - 抽屉激活一个过期租户（另一处先激活再冻结）得到 409 `TENANCY_STATE_CONFLICT`，断言页面显示服务端原文。
  - 断言页面上显示的总数；翻到第 2 页或切换每页条数，断言请求带对应的 `skip` / `take`。
  - 关键字筛选与状态筛选断言请求带 `keyword` / `status` 参数，以区分服务端筛选与前端过滤。
- [ ] 409 文案分流：
  - 状态冲突（`TENANCY_STATE_CONFLICT`）显示服务端消息，不再用编辑冲突的「当前修改未覆盖他人的更新」。
  - 抽屉打开时不再重复页面级 409 提示。现在同一个 409 会出现三处：表单根错误、抽屉提示、页面提示。
- [ ] 开发代理守卫：
  - `vite.config.ts` 在开发服务器监听地址不是回环时拒绝启动，因为代理的默认身份是平台超管。
  - README 注明 `vite preview` 继承同一代理。
- [ ] CI 触发：`tenant-ui.yml` 的 paths 补上宿主装配用到的共享后端，包括 `packages/Qian.*/**`、`Directory.*.props`、`global.json`、`schemas/**`、`contracts/**`。这些共享包改动后也要跑页面七步。
- [ ] 包形态：
  - `react` / `react-dom` 改为 peerDependencies，在 S1-YUE-001 远程加载之前完成。
  - `TenantPage.tsx` 列表请求里手写的状态字面量联合改用生成类型 `Tenant['status']`。
- [ ] 列表端点 HTTP 补测：
  - `status` 非法值与 `keyword` 超过 200 字符时返回 400，pointer 分别为 `#/status` 和 `#/keyword`。
  - 关键字里的 `%` 与 `\` 转义各有一个有区分度的用例。
  - 空租户号、空名称、PUT 名称超长三种情况，在 HTTP 层返回 400 并断言 pointer。
