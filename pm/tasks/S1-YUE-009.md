## 背景

`@yue/sdk`：注册表 API（导航 / 设置 / 命令 / 预览器 / 控件 / 客户端动作，可导出 JSON）、`PlatformClient`、请求拦截器链（鉴权刷新队列、租户头、大数处理）、i18n（key、zh-CN / zh-TW / en-US、远程语言包）、mock 中间件、`.d.ts` 契约、SSE 事件类型由 JSON Schema 生成；`@yue/biz` 基础版：ApiSelect、DictSelect、OrganizeSelect、UserSelect、RoleSelect、菜单 / 按钮授权树、IconPicker，全部经注入的 `PlatformClient`。

## 验收

- [ ] E2E：参考应用用 `OrganizeSelect` 选部门、`UserSelect` 选人，数据来自本租户目录
- [ ] UT：注册表可导出 JSON；拦截器链在令牌过期时合并并发刷新
- [ ] UT：`@yue/biz` 组件不直接发请求，只经注入的 `PlatformClient`；i18n 全部走 key
