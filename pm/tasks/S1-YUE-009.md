## 背景

`@yue/sdk`：注册表 API（导航 / 设置 / 命令 / 预览器 / 控件 / 客户端动作，可导出 JSON）、`PlatformClient`、请求拦截器链（鉴权刷新队列、租户头、大数处理）、i18n（key、zh-CN / zh-TW / en-US、远程语言包）、mock 中间件、`.d.ts` 契约、SSE 事件类型由 JSON Schema 生成。

S1-DEC-024 / R109 拆分：`@yue/biz` 基础版（ApiSelect、DictSelect、OrganizeSelect、UserSelect、RoleSelect、菜单 / 按钮授权树、IconPicker）与原验收 3 移到 S1-YUE-010；原验收 1（参考应用用 OrganizeSelect / UserSelect 选目录数据）与 S1-IDP-010 验收 2 同义，合并到 IDP-010。本任务不再依赖 S1-YUE-007 与 S1-IDP-010，排在 YUE-007 之前：form、data、租户运营页面与 biz 都经它取数、取文案、用 mock 测试。

## 验收

- [ ] UT：注册表可导出 JSON；拦截器链在令牌过期时合并并发刷新
- [ ] UT（R109，来自背景）：i18n 全部走 key，内置 zh-CN / zh-TW / en-US 并可加载远程语言包；mock 中间件替换网络层后调用方代码不变，供 form、data、biz 与页面测试使用
