## 背景

GW-001 的真实 Linux NativeAOT 探针已发布失败，Data/Audit 的 EF 运行时模型和查询路径与现有预编译模型安全守卫存在结构冲突。需选择原生 PostgreSQL Data/Audit Provider 路径、受约束 EF 预编译技术验证，或暂只推进安全宿主并保留 AOT 阻塞；不得用 JIT、空 Provider 或关闭安全检查冒充最终验收。具体证据和可审方案见决策文档。

## 验收

- [x] 产品负责人选择最终 AOT 的数据与审计路径，或明确只先推进安全宿主并保留 AOT 阻塞
- [x] 确认 Provider 与默认组合的调整边界；现有 EF/RLS 安全约束不得被静默放宽
- [x] 选择结果回写决策文档、关联 ADR 与任务依赖；如需拆分，逐条迁移验收，不提前关闭 GW-001 / DEP-008 的最终门
