## 背景

ADR-020 §7 第 6 条沿 ADR-019 §7：Qian 包族许可证（MIT / Apache-2.0 / 源码可见但限制多租户 PaaS 运营）与分发渠道（S1 只发 GitHub Packages，是否以及何时公开到 nuget.org / npm）。它决定能否公开 feed、ISV 能否再分发，并影响 7.2.4 社区市场与 `qian add` 的包源。

## 验收

- [ ] 许可证结论写入 ADR-019 §7 与 ADR-020 §7 第 6 条，并在所有 `Qian.*` / `@qian/*` / `@yue/*` 包元数据中落地
- [ ] 分发渠道结论：S1 GitHub Packages 私有 feed 的组织与权限方案；公开 feed 的前置条件与时点
- [ ] 7.2.4 社区市场「只发现、不自动信任」与包源白名单按结论回填
