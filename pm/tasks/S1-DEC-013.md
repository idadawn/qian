## 背景

2026-10-10 对 Cody 完成的 S1-KUN-005 / S1-KUN-002 / S1-KUN-006、S1-RT-008 / S1-RT-002、S1-IDP-001 做验收复核：本机实跑 Qian 全量 243 项 .NET 测试、Kun 侧 133 项单元与 42 项集成测试（Docker 真容器）全部通过，六项维持 done；发现两处文档与实现的口径不一致和一个跨任务缺口，产品负责人授权按推荐口径处理（裁决编号 R63、R64）。

## 验收

- [x] R63 消费端幂等：Kun 的 `IProcessedMessageStore` 只有 Redis 实现，S1-KUN-002 第 3 条验收实际以 Redis `idemp:` 键断言。PRD §07 7.10 改为「Redis 幂等键默认，PG `processed_messages` 兜底表为 S1-EVT-001 可选项」，ADR-008 D8.4 记录，S1-KUN-002 与 S1-EVT-001 补记
- [x] R64 Definition 包的 Kun 依赖：`Qian.Identity.Abstractions` 直接引用 `Kun.EventBus`（Kun 未拆 `.Abstractions`），与规格 §6.1 / ADR-019 D19.2 不符且依赖图门禁不检查 `Kun.*`。S1-IDP-001 第 1 条验收按实际改写，包 README 登记延期项，新建 S1-KUN-010 跟踪上游拆包与 check_deps 白名单
- [x] 缺口：三项 Kun 修复未发版、`KunVersion` 仍 2026.10.8。新建 S1-KUN-009（Kun 2026.10.9 发版 + KunVersion 升级），并加进 S1-AUD-001、S1-AZ-001、S1-CFG-001、S1-DATA-001、S1-EVT-001、S1-FILE-001、S1-RT-006、S1-RT-015 八个任务的 depends
