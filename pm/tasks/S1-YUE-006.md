## 背景

AppShell 单一侧栏布局（Q38）、Page / PageHeader / ColPage / LeftTree、`menuTypeRegistry`、Preferences、租户切换器、兜底页；认证页族：账号密码、SSO 跳转与回调、多租户二次选择、登录过期弹窗；验证码登录、忘记密码 P1；Captcha P2。

S1-DEC-024 / R111：`@yue/shell` 是库，`qian.shell` 是用它的部署单元（yue 规格 §5.2）。本任务的认证页族与租户切换器经注入的 `AuthProvider` 接口工作，对 `@yue/sdk` 的 mock 中间件验收；接 qian-identity 的真实登录流程（OIDC code + PKCE、selection_token、令牌重签）归 S1-YUE-002。菜单类型注册表建在 `@yue/sdk` 的注册表 API 上（规格 §3.1），登录表单用 `@yue/form`（shell → form 是同层唯一例外），所以 depends 加 S1-YUE-009、S1-YUE-007。

## 验收

- [x] E2E（R111 改写）：在靶场里，认证页族经注入的 `AuthProvider` 与 mock 中间件完成账号密码登录、SSO 跳转与回调页（回调失败时显示错误态）、多租户二次选择；mock 返回 401 且刷新失败时弹出登录过期弹窗；令牌不出现在 URL；接 qian-identity 的真实流程与 S1-YUE-002 验收 1 同义，已合并到 YUE-002
- [x] UT：`menuTypeRegistry` 支持页面与外链两类并可扩展；Preferences 注入与读取
- [x] CI：a11y critical = 0；兜底页 403 / 404 / 500 / 离线各有 Rspress 场景示例（R111：原文写 story，ADR-022 已移除 Storybook）
