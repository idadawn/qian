## 背景

与 7.4 互为前置、契约先行：Definition 暴露 `ctx.Authz` 并再导出 `Kun.Authorization` 端口（`IPermissionChecker` / `IDataPermissionFilter` / `IFieldPolicy`；端口归属见 ADR-019 §7 待确认）；`PermissionDefinition`（资源类型、动作、风险级别、step-up、终端）；权限点命名规范 `<plugin-id>:<resource>:<action>`（R9）；`Check / BatchCheck / ListAllowedActions / ListPermissions / Explain` 接口形状；结构化错误码目录（`AUTHZ_DENIED`、`CONSTRAINT_MUTEX`、`CARDINALITY_USER_LIMIT`、`PARTIAL_SUCCESS` …）与多语言文案 JSON 导出。

## 验收

- [ ] UT：`Qian.Authz.Abstractions` 只依赖 `Kun.Authorization` 端口、`Kun.*.Abstractions` 与 `Qian.Runtime`，通过 PublicAPI 分析器

- [ ] UT：错误码目录与多语言文案导出为 JSON 并符合 `ErrorDetail` 约定
