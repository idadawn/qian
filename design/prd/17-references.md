# 17. 借鉴声明

> 本页由构建脚本镜像自仓库 [`docs/prd/17-references.md`](https://github.com/idadawn/qian/blob/main/docs/prd/17-references.md)，请修改源文件，不要改本页。

> 状态：草案 v1 · 更新日期：2026-10-06 · 决策引用：ADR-001、ADR-002、ADR-005、ADR-007、ADR-012、ADR-013、ADR-015、ADR-016、ADR-020 · 上级索引：[README](/design/prd/index.md)

本章说明 Qian 借鉴了哪些外部项目、以什么许可证、借鉴了什么、以及我们的态度。态度分四种：**引入代码**（作为依赖或搬运代码，须遵守其许可证）；**只借鉴设计**（不引入任何代码，含许可证限制与我们主动选择两种原因）；**运维侧使用**（作为基础设施运行，不进入产品代码）；**不采用**（评估后放弃，留作记录）。许可证以引入时在仓库内核验为准，本表为规划期口径。

> 一套商业低代码产品的功能集作为需求参照：只借鉴其功能全集、概念模型与反例教训，不引入任何代码、品牌、资源与源码路径；全文统称「参考平台」。

## 17.4 商业平台的公开设计模式

以下为公开文档中的设计模式，无代码可引入，只借鉴思路：元数据驱动多租户内核与透视索引、托管包与命名空间、属性级可定制性、推送升级（CRM 平台生态）；托管层 / 非托管层分层叠加与「上层优先 + 容器型合并」（企业数据平台）；定制跳过 + 升级三选一（ITSM 平台）；模板型 / 商品型两种商品与同源导入升级（国内零代码市场）；平台托管运行时与「数据不出平台」徽章、按安装隔离存储、小版本自动推送 / 大版本需同意（协作平台开发者生态）；双轨席位（协作套件 aPaaS）；接口调用许可（企业 IM 开放平台）；元数据 + 微服务制品合一的应用模板（云厂商业务中台）。来源见 `research/notes/d3-web-market.md`。

## 17.5 我们的贡献意向

- Kun：S1 修复的关键缺口以上游 PR 回合（设 1 个迭代的回合入期限，否则维护补丁包）。
- OpenIddict / MCP C# SDK：使用中发现的 AOT 兼容与协议一致性问题以 issue / PR 回馈。
- yue：以私有 npm 分发为主；S3 可选、S4 必做 shadcn 私有 registry + MCP Server 面向 ISV 与 Agent。
- 被替代或放弃的方案在本表保留记录而不删除，供后续复核。
