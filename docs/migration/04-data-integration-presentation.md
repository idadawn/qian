# 迁移映射 04 · 数据中心、集成中心、消息与调度、门户、报表、打印、大屏、文件预览、AI 中心清单

> 来源基线：D（数据 / 集成 / 消息 / 调度 / 门户 / 报表 / 打印 / 大屏 / 预览）。相关决策：ADR-004 数据库、ADR-007 Apollo 与密钥、ADR-008 事件、ADR-010 网关、ADR-011 元数据、ADR-015 模型网关、ADR-016 iClaw 边界、ADR-017 部署；PRD §07（S1 技术组件）、§08、§09（门户 / 报表 / 开放 API）、§10（S4 预留）。
> 口径与优先级标记同映射 01。术语：「数据接口」= 参考平台「数据集 / 数据服务」的统称，定义层带读写属性，消费侧叫「数据绑定」。

## 0. 本域的迁移判断

本域子域多而同构，迁移的核心原则是**横切能力只在内核实现一次**：可发布元数据框架（草稿 / 发布 / 归档 + 生效指针 + 快照）、导入导出框架（判重策略、id 重映射、依赖重连清单）、引用登记、分享链接、预览票据、编码规则、控件注册表契约。参考平台在这些点上每个子域各写一遍（门户 / 报表 / 打印三套状态机命名不一、五种专有包后缀）。实现层面必须外置的进程内状态（WebSocket 连接池、公告延时队列、线程休眠重试、无集群配置的调度器）、必须收口的凭据（三处来源且明文）、必须关闭的任意 SQL / 任意 URL 代理 / 匿名上传，是本域最集中的「必须修正」。阶段上按补充裁决：数据连接与类型系统、数据接口契约、通知、调度、实时推送、凭证引用在 S1；数据建模、接口设计器、打印、文件预览在 S2；门户设计型、报表、开放 API、分享链接在 S3；大屏延后且不复用参考平台大屏源码；AI 中心除模型服务网关外全部 S4。

## 4. 必须修正的做法

| # | 参考平台做法 | 风险 | Qian 替代做法 |
|---|---|---|---|
| 1 | WebSocket 连接池、公告延时队列、线程休眠重试、无集群配置调度器等进程内状态 | 多副本下丢失或重复 | Redis Pub/Sub 或消息总线扇出；调度器集群单活或分片；延时任务走调度；重试走队列 |
| 2 | RabbitMQ 单队列、非持久化、先 ack 后处理（至多一次）；多实例竞争不能广播 | 丢消息 | 统一事件信封 + 持久化 + 死信 + 广播与竞争两种订阅（ADR-008） |
| 3 | 定时任务以创建者（缺失则 admin）身份签 JWT 回调本机绝对地址 | 越权、地址失效 | 服务名寻址 + 签名 + 幂等键 + 受限服务身份 + 结果回写 |
| 4 | 凭据三处来源且明文入库、详情接口回传密钥；部署级共享对称密钥带默认值且一钥多用 | 泄密 | 单一凭证来源（secretRef → K8s Secret / Infisical）；配置只存引用（ADR-007） |
| 5 | SQL 文本直执行、任意 URL 代理携带用户 token、匿名上传与下载 | 注入、SSRF、泄露 | SQL 文本为高级权限 + 只读账号 + 限额；HTTP 执行器白名单；下载鉴权 |
| 6 | 「发送中」从未写入、每次失败各写一条、重试全员重发、一键清空删掉站内信 | 不可观测、骚扰、误删 | 终态记录 + 尝试次数；发送中态；定向重试；清空只清监控 |
| 7 | 服务端出图依赖 System.Drawing，Linux 容器中静默失败且异常被吞 | 条码 / 二维码丢失 | 跨平台图形库（SkiaSharp）+ 失败告警 |
| 8 | 77 个 JSON 文本列承载设计器产物，无 Schema、无约束、无 schema 分域 | 不可校验、不可迁移 | jsonb + 注册在内核的 JSON Schema 版本号；按限界上下文分 schema；多值一律关系表 |
| 9 | 预览服务、报表服务各有一套连接串 / Redis / JWT；预览副本落后上游安全修复 | 运维分裂、漏洞 | Helm 子 chart 随插件安装、配置入 Apollo、票据内核签发、版本钉住并定期跟随 |
| 10 | 转换后的字段退化为字符串排序 | 排序错误 | 服务端按原始类型排序后再翻译 |
| 11 | 大屏分享密码前端校验、分享实际需登录态 | 名不副实 | 内核分享链接服务端校验 |
| 12 | 门户每控件 PC / APP 两套属性、两端物料表不同步 | 元数据双份 | 单一注册表 + 端维度覆盖 |
| 13 | 开放接口自定义 AES 加密方案、用户级 AppSecret、白名单疑比对服务器自身 IP | 伪安全 | 网关标准鉴权（client_credentials）+ scope + 限流 |
| 14 | 用户表冗余门户 id 列表 | 模型耦合 | 租户 / 角色 / 用户 → 门户关系表 |
