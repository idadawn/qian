Markdown 链接

本页由 website/scripts/build-versions.ts 从仓库钉版文件生成（ADR-021 D21.2 第 3 条），不要手改；改版本去改下表列出的源文件。

「哪个 Qian 配哪个 Kun」只看这一张表：Kun 的版本在 Directory.Packages.props 的 KunVersion 写一次，代码引用的 Kun.* 包、Kun 框架小节与 Kun API 参考都按它锁定。

Kun 的同日修复版 -hotfix.N 是推送 nuget.org 的正式修复，但 NuGet 按预发布排序；Kun.* 一律以 [$(KunVersion)] 精确钉定，不依赖最新稳定版排序（ADR-021 D21.3 补注）。
