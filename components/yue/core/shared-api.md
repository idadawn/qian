# 通用上下文 API

### DirectionProvider

| 属性 | 类型 | 必填 | 默认值 | 说明 |
| --------- | ---------------------------- | -- | ----- | --------------------------------- |
| children | `React.ReactNode` | 否 | 未指定 | 以 TypeScript 类型约束为准。 |
| direction | `TextDirection \| undefined` | 否 | 'ltr' | The reading direction of the text |
