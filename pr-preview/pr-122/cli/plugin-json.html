#组件清单 plugin.json

Markdown 链接

本页由构建脚本同步自 组件模型规格 §3（仓库 docs/prd/specs/component-model.md），不另写；请修改规格源文件。

清单文件名与格式已定稿：.qian-plugin/plugin.json（JSON，便于 JSON Schema 校验与源生成器合并）；profile 与 patch 继续用 YAML（人手编辑、需要注释）；qian doctor --migrate-manifest 负责从 v1 qian-plugin.yaml 迁移（ADR-020 §7 第 2 条，已拍板）。

#3.4 字段逐项表

分级：S1 = S1 校验器与宿主都消费；S2 / S3 = 校验器接受结构、宿主到该阶段才消费语义（低阶段宿主输出 warning: field reserved for S2+，沿 v1 D10）。

根与标识

字段类型必填说明分级
$schemaconst "https://qian.dev/schemas/plugin/v2"否编辑器提示；版本以文件路径 .qian-plugin/plugin.json 为准S1
id^[a-z][a-z0-9-]*(\.[a-z][a-z0-9-]*)+$，≤ 128是反向域名，发布后不可改；qian. 前缀保留给官方组件S1
versionSemVer 2.0是与 Kun CalVer 独立S1
descriptionstring，10–500 字是面向人；模型看 skills / tools 的描述S1
author{ name, email?, url? }是市场的 publisher.verified 在 S3 另行维护，不在清单S1
licenseSPDX 或 LicenseRef-*是Qian 包族许可证已定为 Apache-2.0（→ §13 第 6 条），官方组件写 Apache-2.0；S3 商业组件的许可证另定S1
engines{ qian?, kun?, yue? } SemVer range否沿 v1 保留；有 ui 表面时 yue 必填，有 runtime.nuget 时 kun 必填S1

展示（interface）

字段类型必填说明分级
displayNamestring ≤ 40 字是市场与目录显示名S1
category^[a-z][a-z0-9-]*$是分类短名；官方分类目录由市场仓库维护S1
defaultPrompt[]≤ 5 条否安装后展示给用户的首批提示词S1
icon / screenshots[]assets/ 下相对路径否截图 ≤ 6 张S1
brandColor^#[0-9A-Fa-f]{6}$否品牌色S1
locales{ [locale]: { displayName?, description? } }否多语言；S1 只校验结构S3

表面指针（surfaces）——相对组件根；省略取默认；指向不存在的路径是 error。

字段默认指向
skills / agents / commands / tools / metadata / schemas./skills 等同名目录目录；metadata/ 承载本组件定义的权限点、默认角色、事件、消息类型——已裁决（R37）
hooks / mcpServers / ui / patch./hooks/hooks.json / ./.mcp.json / ./ui/manifest.json / ./config/qian.patch.yml文件

运行时（runtime）——无代码组件省略整个对象。

字段类型必填说明分级
formmodule | service | function | ui | package有 src/ 时是代码的物理形态（v1 kind 退化而来，§3.6）：进程内程序集 / 独立工作负载 / Wasm 函数 / 仅前端远程模块 / 低代码元数据包。组合包不写；连接器组件按实现取 module 或 service（R28）S1（function、package S2）
nuget[] / npm[]{ id | name, version, digest? }[]否精确版本；digest 为包内容 sha256:，S1 可选、S3 第三方必填S1
entrystringmodule 时是.NET "<Type>, <Assembly>"（实现 IQianPlugin）；TS 为 npm 包导出名（默认 default）S1
image^oci://.+@sha256:[0-9a-f]{64}$service 时是只接受 digest 引用（ADR-002 D2.7）；service{ protocols, resources, health } 沿 v1 components.serviceS1
wasm / limits…@sha256:… / { fuel, memoryMiB, timeoutMs }function 时是预留S2
configSchema相对路径有 config 时是JSON Schema 2020-12；装载器在 Apply 前校验S1
dbSchema^plugin_[a-z0-9_]+$否默认 plugin_<id 以下划线连接>S1

依赖、提供、作用域

字段类型必填说明分级
inject[]服务键数组，每项 ^[A-Z][A-Za-z0-9]*(\.[A-Z][A-Za-z0-9]*:[a-z][a-z0-9-]*)?$是（可空）依赖的服务键：<Key>（单例 seam）或 <Key>.<Registry>:<name>（注册表 seam 的某个具名注册，R38）；全部就绪才 Apply；装载顺序由此推导S1
optionalInject[]同上否可选依赖：缺失时仍 Apply，TryInject 为空S1
provides[]同上是（可空）Apply 时会 Provide 的键，或向注册表子服务 Register(name, …) 的「注册表键:名称」（R38）；与 inject 不相交；代码组件由源生成器派生S1
scopes[]global | tenant | app | agent-session 非空数组是允许挂载的 scope 种类；条目 scope 不在列表内即失败；["global"] = 只能作为全局条目挂载S1

策略（policy）

字段类型必填说明分级
tiersystem | official | partner | private | community是信任等级（ADR-002 D2.4）；决定允许的 form、sandbox、hooks 类型与进程边界（§11.1）S1
sandboxnone | worker | iframe | wasm | workload是none 共享进程 / 外壳直接加载；worker / iframe 不可信 UI；wasm 函数；workload 独立工作负载S1
authenticationON_INSTALL | ON_USE是安装时一次性批准反向权限与密钥，或首次使用时由当前用户授权（S3 连接器组件）S1（ON_USE S3）
profiles[]string[]否推荐 / 允许的 profile；不在列表的 profile 安装需 --force-profileS1
requiredboolean，默认 false否true = 该组件的条目不可被任何 scope patch 禁用或遮蔽，qian remove 拒绝卸载（取代 v1 alwaysEnabled，R34）；只允许 tier: systemS1
egress[]string[]，每项 <host>[:<port>]（host 可含 *. 前缀）否；连接器组件必填允许的出网目标（R28）；为空 = 默认拒绝出网（NetworkPolicy / 出口代理）；hooks.json、.mcp.json 的 url 域名必须在其中S1
permissions{ platform[], data[], secrets[], ui{ connectSrc[] } }否反向权限，沿 v1 permissions.* 保留（含义见 plugin-manifest.md §3.2；v1 permissions.egress 升为 policy.egress）；安装时列出并批准，升级新增即重批。落点已裁决（R37）S1

根对象 additionalProperties: false，接受 ^x- 自定义字段。

#3.6 v1 → v2 字段迁移对照

qian-plugin.yaml → .qian-plugin/plugin.json；CLI qian doctor --migrate-manifest <qian-plugin.yaml> 输出 v2 草稿（文件名与格式 → §13 第 2 条）。

v1 字段v2 落点备注
schemaVersion$schema（可选）版本由文件位置决定
id / version / license同名不变
kind: module | service | package | function | uiruntime.form 同名值（service 加 runtime.image，function 加 runtime.wasm，ui 加 surfaces.ui）顶层分类改为表面
kind: connector不是 runtime.form 取值。连接器 = 为某个 seam 提供 Provider 的组件：向该 seam 的注册表子服务按名称注册，provides 写 ["Identity.Connectors:oidc"] 这类「注册表键:名称」（R38）+ policy.egress[] 声明出网目标（域名 / 端口）；runtime.form 按实现取 module | service（R28）S3 policy.authentication: ON_USE 的连接器同此；例见 §6.3 身份连接器
kind: bundle + components{}组合包：有 config/qian.patch.yml，可携带多个组件（经 runtime.nuget[] / npm[] 引用或内联 components/<id>/），无 runtime.form；v1 components 下各组件各自成为独立组件。应用 = 组合包 + marketplace 条目（R28）—
role删除由 provides[]（Provider）、inject[]（Consumer）与表面组合（App）体现
