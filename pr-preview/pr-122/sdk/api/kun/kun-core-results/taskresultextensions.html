Namespace: Kun.Core.Results
Assembly: Kun.Core.dll

Asynchronous railway-oriented extensions for Task receivers whose result type is Result or Result<T>. Follows ADR-011.

public static class TaskResultExtensions

#Remarks

Each operation provides two delegate-shape overloads:

  • a sync-delegate variant (no CancellationToken)
  • an async-delegate variant that accepts a CancellationToken and forwards it to the delegate.

Failure inputs short-circuit without invoking the delegate. Faulted or cancelled source tasks surface through await per normal .NET semantics — neither a Result failure nor a wrapped exception.
