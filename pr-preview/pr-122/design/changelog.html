#变更日志

Markdown 链接

本页由构建脚本镜像自仓库 docs/CHANGELOG.md，请修改源文件，不要改本页。

记录对读者可见的变化：新文档与新规格、新组件与命令、破坏性变更。按日期倒序，每条一个二级标题 ## YYYY-MM-DD 标题，下面一两行说明并链接到详情。文档站首页「最新动态」取最近 4 条（docs-site.md §2a.1）。

#2026-10-15 执行入口拒绝超出 decimal 范围的数（S1-RT-024）

通用执行入口的请求体里有绝对值超过 decimal 范围（约 7.9e28）的数时返回 400 BAD_REQUEST，不再返回 500；输入 Schema 的 enum / const 取值含这类数的能力在登记阶段以新规则 unsupported-number 拒绝。详见 Qian.Capabilities。

#2026-10-15 执行入口补不可重放码，参考应用能力标为 pii（S1-RT-021）

聚合 OpenAPI 为写类能力列出 409 CAPABILITY_REPLAY_UNAVAILABLE 及其两种 reason。参考应用的 customer.create、customer.list、customer.get 响应含客户名称，dataClassification 改为 pii：经通用执行入口带同一幂等键重放 customer.create 改为返回 409（data_classification）。运维手册新增「部署步骤：平台宿主装配」（platform 宿主必须调用 AddQianCapabilities()）与「过期幂等回执清理」两节。详见 Qian.Capabilities。

#2026-10-15 能力登记期契约检查与幂等回执上限（S1-RT-020）

平台宿主调用 AddQianCapabilities() 后，ctx.ProvideCapability 在登记时生成目录条目并预编译输入校验器，不合格的契约（输入含租户字段、Schema 无法可靠校验等）以 CapabilityContractException 拒绝，组件挂载失败。通用执行入口的幂等回执按数据分级与组件配置 receiptMaxBytes（默认 64 KiB）决定是否保存响应体，不保存时同键重放返回 409 CAPABILITY_REPLAY_UNAVAILABLE；Qian.Capabilities 新增迁移 InvokeReceiptLimits。Qian.Data 新增「迁移执行与 RLS 核查」一节（迁移必须经迁移器执行，附核查 SQL），运维手册新增「部署步骤：数据库迁移」。详见组件规格 §9.5 与 Qian.Capabilities。

#2026-10-15 数据契约冻结、组件元数据与文档预算整改（S1-QA-010）

data/v1 契约 按 R80 明确 frozen 状态、修订规则和已知例外，统一 $id 前缀并补结构测试；yue manifest 的属性元数据（含嵌套）递归取自 TS 注释，不存在的属性拒绝导出；文档站预算 按 R55 调为 120 MB，#95 合并时实测 96.2 MB。

#2026-10-15 数据连接连通测试的出网约束与凭据错误（S1-DATA-005）

  • 连通测试先解析目标主机并逐个检查地址：缺省拒绝回环、链路本地（含云元数据）、100.100.100.200、未指定、组播与广播地址。运维可经 QianDataConnectionOptions.Egress 追加拒绝网段或限定放行网段；被拒返回 DATA_CONNECTION_TARGET_DENIED，不连接也不读取密钥，放行时只连检查过的地址。
  • 租户密钥不是 UTF-8 文本时，PG 方言返回 DATA_CONNECTION_CREDENTIAL_INVALID，不再是 500。见 Qian.Data。

#2026-10-14 能力目录信封契约、别名 Link 头与通用执行入口规范化（S1-RT-019）

GET /api/capabilities 的响应冻结为 contracts/v0/capability-catalog（items、ttlMs、cacheScope），ttlMs 来自组件配置 catalogTtlMs；/api/kernel/capabilities 别名同时返回 Deprecation 与 Link: <后继路径>; rel="successor-version"；POST /api/capabilities/{plugin}/{name}/invoke 先按条目 inputSchema 校验（400 INPUT_INVALID），写类能力支持 Idempotency-Key（24 小时内重放返回首次响应并带 Idempotent-Replayed: true）；Qian.Capabilities 随包提供 EF 迁移（偏好表、回执表，经 Qian.Data 生成器带 RLS）。详见组件规格 §9.5 与 PRD 7.2.1。

#2026-10-14 yue 组件文档迁入 Rspress（S1-YUE-005）

51 个组件入口、141 个公开组件/部件的 Props、令牌页与可编辑的真实演示统一进入现有 Rspress。共用示例及 126 个状态场景迁移到独立 Playwright，离线编辑器资源随站点发布；移除旧文档应用与依赖，保留原有八项门禁。使用说明见 core 主文档。

#2026-10-14 身份事件载荷不再重复信封字段（S1-DEC-020、S1-IDP-011）

破坏性变更：五类身份事件的载荷去掉 event_id、occurred_at、tenant_id，构造参数随之减少，IdentityIntegrationEvent 不再实现 Kun 的 IIntegrationEvent；三项只由 Qian.Events 写入端生成在信封上。v1 尚无生产方、消费方与已发布包，按 S1-DEC-020 就地修正，此后的破坏性变化才升 v2。见 身份事件契约 与 ADR-008 D8.7。

#2026-10-14 记录变更事件改为登记载荷（S1-DATA-004）

qian.record.changed.v1 按 Qian.Events 的模型发布：[IntegrationEventId] 移到 RecordChangedPayload，RegisterRecordEvents 登记载荷，信封只由写入端生成一层；RecordChangedEvent 改为 after Hook 视图，由 RecordChangedEvent.FromEnvelope 从收到的信封派生。破坏性变更：删除 DataContractJson.RecordChangedEventTypeInfo，EnsureConsistentContext 移到载荷，改为核对当前租户与事件来源。线上信封、payload Schema 与 fixture 不变，见 数据契约规格 §6。

#2026-10-14 统一 Rspress 组件文档与验收口径（S1-YUE-005、S1-DOCS-002）

产品负责人决定不再使用 Storybook；ADR-022 记录真实组件试构建结果、Props 默认过滤问题及离线编辑器要求。YUE-005 重新打开承接替换，DOCS-002 复用接线；本次为评估与规格修订，迁移实现尚未完成。

#2026-10-14 基准类型、PG 方言组件与数据连接档案（S1-DATA-003）

  • 10 个系统基准类型作为种子数据随 Qian.Data.Abstractions 发布；新增方言 SPI qian.data.dialect/v1 与 PostgreSQL 方言包 Qian.Data.Dialect.Pg，DialectTypeMapping 拒绝超出长度、精度、小数位或取值区间的字段定义。
  • IDataConnectionRegistry：按租户隔离的连接档案，口令只存租户 secretRef，连通测试在使用点解析，详情不回传密钥。新增 Qian.Data.AspNetCore 提供 GET /api/data/meta/types 与 /api/data/connections（含 POST /connections/{id}:test）。见 Qian.Data。

#2026-10-14 多副本迁移协调、雪花 ID 与序号服务（S1-DATA-002）

  • IDataMigrator：按 schema 取 PostgreSQL advisory lock 后执行 EF 迁移，同时启动的副本只有一个执行 DDL；K8s 迁移 Job 用 --migrate-only，在线副本启动时发现未应用的迁移即拒绝启动。
  • ISnowflakeIdGenerator（WorkerId 经 Redis 租约 qian:snowflake:worker:{n} 分配，带高水位，编号回收复用不重 ID）与 ISequenceService（规则 'SO' + yyyyMMdd + seq(6)，单条 upsert 原子取号，规则修改后从 1 开始）。见 Qian.Data。
