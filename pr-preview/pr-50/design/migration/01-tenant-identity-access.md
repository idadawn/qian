# 迁移映射 01 · 租户、组织、身份与 SSO、权限、系统管理、控制台与个人中心、消息入口、移动端

> 本页由构建脚本镜像自仓库 [`docs/migration/01-tenant-identity-access.md`](https://github.com/idadawn/qian/blob/main/docs/migration/01-tenant-identity-access.md)，请修改源文件，不要改本页。

> 来源基线：S。相关决策：ADR-004 隔离、ADR-005 身份、ADR-006 鉴权、ADR-007 Apollo、ADR-009 审计、ADR-010 网关；PRD §07、§13、§11。
> 口径：「沿用概念」= 借鉴概念模型或交互、实现全部重写；「重新设计」= 概念与实现都换；「不做」= 本期不进范围。优先级：P0 = 阶段退出标准依赖的必做；P1 = 该阶段可选 / 下一阶段必做；P2 = 视客户需求。阶段以决策清单为准，与基线不一致处在 §5 注明。

## 0. 本域的迁移判断

本域是平台的可信计算基，S1 工作量最大。参考平台的**概念模型**值得借鉴（统一授权表 + 多层主体、身份收窄、数据权限方案、租户控制面与业务面分离、消息三层模型），**实现**多处不可照搬（接口层权限恒 `true`、会话不可吊销、租户解析 fail-open、服务间信任仅靠请求头、SSO 用 IFrame + MQ 单向同步、密码 MD5、配置 100 余键扁平堆放）。Qian 路线：OpenIddict 自建 `qian.identity` 作唯一 issuer（ADR-005）、Person + Membership、上游联邦一律连接器插件、权限点由清单声明并在 `qian.authz` 单一判定点执行（ADR-006）、租户控制面独立并带显式状态机。

## 5. 未决问题

1. **组织目录归属**（已裁决 R1）：S1 组织目录最小集作为 `qian.identity` 的子模块交付（PRD §07 7.4.3），不独立为系统插件；本文件沿用 `qian.directory` 作为目录能力家族的 ID（见 README §8 问题 1）。
2. **企微连接器与 TOTP 升为 S1 必做**（基线 S 均 S1 可选）：S1 身份域增加约两个插件，需在 PRD §15 确认不挤压唯一 issuer 与会话中心。
3. **短信供应商与凭据来源**：短信 S1 必做，供应商与密钥库（K8s Secret / Infisical）未定。
4. **`qian.realtime` 阶段**（已裁决 R1）：纳入 S1 系统插件清单，优先级 S1·P1（基线 D 为 S1 必做，P 基线为 S2）。
5. **租户自助申请与邀请格式**（Q13 交 Qian 自行设计）：审核是否默认自动通过、邀请是否带角色与应用、有效期默认值。
6. **商密**：Q18 对商密不做假设；若有 SM2 / SM3 要求，令牌签名算法需提前验证。
7. **登录策略默认值**：并发上限默认 5、锁定阈值、初始密码强制等是否沿用参考平台数值作出厂默认。
