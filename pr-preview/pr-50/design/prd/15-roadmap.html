    #15.1 阶段总览

    阶段名称一句话目标退出标准（摘要，全文见 ROADMAP）状态
    S1技术底座开发者用代码在 Qian 上写出一个多租户应用登录 / SSO、鉴权、数据存储、文件上传、配置、网关、事件、审计全部由平台提供；一个官方 module 插件能独立出修订、逐租户迁移、回切⬜
    S2低代码构建搭建者不写代码建出带审批的应用并授权跑通「建应用 → 建表单与列表 → 走审批 → 授权给租户用户使用」；同一应用包在两个租户分别安装、各自配置、独立升级互不影响⬜
    S3面向客户租户自助选购、开通、配置租户能从应用市场选购并开通应用，自助配置 IdP 与品牌⬜
    S4AI 原生 Agent 平台Agent 发现、调用、编排、生成平台能力Agent 能发现、调用、编排乃至生成平台能力与应用⬜

    状态符号：✅ 已完成 · 🚧 进行中 · ⬜ 未开始。
