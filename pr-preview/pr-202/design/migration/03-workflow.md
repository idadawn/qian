## 0. 本域的迁移判断

参考平台的流程子系统是「.NET 业务编排 + Java 引擎双进程双库」：引擎只回答「当前在哪、下一步能去哪」，其余约 2.6 万行全是审批域业务（会签 / 或签 / 加签 / 退回 / 转审 / 委托 / 撤回 / 抄送）。这意味着**换引擎的成本远小于重写审批域，审批域才是工作量大头**。Qian 按 ADR-012：自研 .NET 轻量审批内核（令牌推进、三种网关、默认分支 = else、单库单事务），复用 Saga 的状态机命名与 Outbox；Elsa 只做 S1 末 PoC 对照，Flowable 只作可选 BPMN 适配器；简单流程与标准流程合并为**一套 JSON 定义、两种视图**，S2 只交付纵向节点树视图设计器（补充裁决 Q22）。参考平台 14 处做法必须修正（§5）：兜底全局 admin、会签停滞、转审改写记录、拼 SQL 判条件、V8 任意脚本、匿名回调等。
