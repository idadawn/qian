# 制品内容摘要共用样例

`content.json` 保存同一份组件原始文件、固定目录摘要和逐文件清单，由 CLI 的 `snapshot` 与注册表的内容快照入口共同消费。样例包含中文路径和 CRLF 字节，避免摘要算法在编码、排序或换行上产生两套规则。

目录摘要沿用组件规格 D4：按文件路径的序数顺序排列，每行是路径、制表符、十进制字节数、制表符、文件 SHA-256 小写十六进制、LF；对整个 UTF-8 清单再计算 SHA-256，前缀为 `sha256:`。摘要覆盖原始字节，不把 JSON 重排或换行转换后的内容作为原件。

元数据在本样例中只是待提交内容；真实权限点与默认角色仍需经相应 seam 的 Schema 和发布准入验证，不表示已实例化角色、验签成功或允许安装。
