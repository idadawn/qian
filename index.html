Qian 文档

Qian 平台基于 Kun 框架构建，前端使用 yue 组件库：组件一条命令装进任何项目，组合起来就是为 Agent 时代准备的多租户平台。

三条起步命令

命令与「开始」部分同源；S1 建设期内随任务陆续可用。

① 装一个组件

qian add identity authz files

在 ASP.NET Core 项目里装身份、鉴权、文件三个组件，不用部署 Qian 平台。30 分钟上手 →

② 配置你的编码代理

npx qian@latest --skill files

把组件的技能装进 Claude Code、Codex 等编码代理；代理先读仓库里的 AGENTS.md。详见下一节 ↓

③ 调一个模型 S1·P1

curl "$MODEL_GATEWAY/v1/chat/completions" \
  -H "Authorization: Bearer $MODEL_GATEWAY_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "chat-default", "messages": [{"role": "user", "content": "你好"}]}'

经模型网关的 OpenAI 兼容端点发一条请求，用逻辑模型名。模型网关 →

最新动态

  • 2026-10-25
    身份适配器与数据组件的登记先后不再影响能力执行（S1-KUN-017）

    Kun 升到 2026.10.25：数据约定与实体审计不再以匿名兜底占住框架当前主体端口，宿主先登记数据组件、后登记身份适配器时能力照常执行（此前一律 403 AUTHZ_DENIED），参考应用、测试宿主与联调栈的绕开写法已撤销。能力宿主的框架当前主体端口若仍解析为匿名兜底，启动即失败并写明改法；只装数据组件、没有身份适配器的宿主照常可用，审计与删除主体写 null。详见 Qian.Plugin.Sdk、Qian.Data。

  • 2026-10-24
    网关路由共享限流（S1-GW-002）

    网关 支持 IP、租户和用户三策略及 Redis 共享固定窗口，超限返回带 Retry-After 的 429，Redis 故障返回 503。路由现在必须显式填写 rateLimiterPolicy；仓库配置已迁移，自定义宿主与 profile 需补充该字段。

  • 2026-10-24
    身份客户端可从私有源安装（S1-IDP-015）

    qian.identity.client 钉定已发布的 Qian.Identity.Client 0.3.0 及归档摘要，移除骨架标记。真实 qian add identity 安装门校验包源、版本、摘要、表面与 lock，再由宿主按清单挂载 Identity 服务并撤销；发行方与客户端标识由宿主显式配置。

  • 2026-10-24
    通用契约 v0 冻结（S1-AGT-005）

    contracts/v0 的六份 Schema 按 R53 / R80 / R119 统一标记为 frozen，后续只接受向后兼容增量，破坏性变更进入 v1。现有字段与约束保持不变；data/v1 引用草稿信封的例外随之解除。

产品能力

按用途找能力：每项一句话，正文只在一个部分写一次。

用 AI 构建

  • 模型网关：一个端点调所有模型，配额、回退、计量（S1·P1）
  • AI SDK：调模型与 Embedding，写 Agent 表面，声明工具副作用与策略
  • Agent 运行时对接：Qian 不写 Agent loop，运行时为 iClaw
  • MCP：组件的 .mcp.json 表面；每租户能力门面（S4）
  • 流程与自动化：审批内核与触发器（S2）
  • 沙箱：隔离执行不可信或 Agent 生成的代码（S4）

构建应用

  • 宿主与框架：独立模式、platform profile、React + yue、与 Kun 的关系
  • Kun 框架：Qian 的底座，.NET 10 微服务框架的模块地图、指南、安全与 API
  • 组件与 qian add：一条命令安装，装上即可用
  • 能力与函数：能力目录；function 表面（S2）
  • 事件与中间件：五种分发模式，waterfall 即环绕中间件
  • profile 与 patch：环境 = profile + 分层 patch
  • yue 与微前端：组件库、外壳与远程模块
  • 存储：文件与数据，租户隔离默认开启
  • 低代码：表单与列表（S2）

多租户平台

  • 租户：租户目录、隔离策略与生命周期
  • 身份与 SSO：OIDC 端点与双层账号
  • 鉴权：权限点注册表与租户域 RBAC
  • 权益：授权 v0；计费（S3）
  • 配置中心：Apollo 与热更新
  • 事件与消息：Outbox 可靠发布
  • 调度与实时：持久化作业与实时推送
  • 市场：上架、信任等级与签名（S3）

保护应用

  • 网关防护：强制认证、路由级限流、可信代理、出网 SSRF 基线
  • 发布保护：制品验签、修订回切、灰度开关
  • 审计：命令级哈希链与实体级同事务审计
  • 密钥：secretRef、按范围授权、轮换

部署与运维

  • GitOps 部署：Argo CD app-of-apps、Kustomize、digest 写回
  • 灰度发布：灰度开关 + profile 滚动更新
  • 修订回切：回到任一保留的修订
  • 可观测：OTel、租户 / 用户 / 插件 baggage、计量事件
  • 模型网关接线：GPUStack → Higress（S1·P1）
